關於呢份手冊

呢份手冊介紹目前 LRCPlus 原始碼版本嘅操作。你用嘅版本同啟用咗嘅外掛可能會影響可用功能。好似 Settings → Lyrics 呢啲路徑就係要喺程式入面揀嘅選單。為咗方便對照畫面，選單同按鈕名稱會保留英文。

手冊有網上版本，亦會隨程式附送。附送版本可以離線閱讀同搜尋。不過，上網搵歌詞同使用線上讀音服務仍然要有網絡連線。

入門

喺 LRCPlus 播放第一首歌

LRCPlus 可以一邊播歌，一邊顯示同步歌詞，亦支援讀音輔助同卡拉 OK 時間。準備一個音訊檔就可以開始。

播放第一首歌

  1. 開啟 LRCPlus。如果出現設定精靈，就跟住指示設定。
  2. 揀 Open → Open Audio…，或者撳 Ctrl + O，再揀音訊檔。
  3. 用 Play 開始或者暫停播放。
  4. 揀 Lyrics 去歌詞畫面，或者揀 Library 返回音樂庫。

加入歌詞

如果有對應嘅歌詞檔，揀 Open → Open Lyrics…（Ctrl + L）。要上網搵就揀 LRC → Search Lyrics。完整步驟可以睇搵歌詞。

試吓用相同檔名。 將 Song.mp3 同 Song.lrc 或者 Song.lrcx 放喺同一個資料夾。如果兩種歌詞格式都有，LRCPlus 會優先用 LRCX。

下一步

  • 加入音樂資料夾到音樂庫。
  • 開啟振假名或者羅馬字。
  • 修改一行歌詞。

你可以由 Settings → General → Relaunch Wizard 再開設定精靈。

音樂同播放

音樂庫、佇列同播放控制

建立音樂庫

  1. 切換去 Library。
  2. 撳 Add Music Folder，揀存放音樂嘅資料夾。
  3. 更改資料夾入面嘅檔案之後，用 Rescan 重新掃描。

用 Remove Folder 管理音樂庫包含邊啲資料夾。

使用播放佇列

揀 Open → Add to Queue…（Ctrl + Shift + O）加入檔案。播放來源可以揀 Library 或者 Queue / Playlist。如果播緊嘅歌曲清單同你預期唔同，檢查吓呢個選項。

喺歌曲入面移動

控制用途
Play / Pause播放或者暫停目前歌曲。
Stop停止播放。
< 5s / 5s >向後或者向前跳五秒。
<< / >>跳去上一首或者下一首。
Volume / Mute調校音量或者靜音。

播放偏好

喺 Settings → Playback 揀輸出裝置、以歌曲或者專輯為單位隨機播放，同播完之後嘅動作：下一首、停止、全部循環或者單曲循環。如果唔肯定用邊個輸出裝置，可以先揀 System Default。

想快啲操作，可以睇鍵盤快捷鍵。

搵歌詞

開啟檔案，或者搵啱版本

開啟本機歌詞

載入歌曲之後，揀 Open → Open Lyrics…，再揀 .lrc 或者 .lrcx 檔。音訊同歌詞用相同檔名有助自動搜尋。額外歌詞搜尋資料夾可以喺 Settings → Files 管理。

網上搜尋

  1. 載入要搵歌詞嘅歌曲。
  2. 揀 LRC → Search Lyrics。
  3. 檢查搜尋資料，再撳 搜尋。
  4. 揀結果並睇預覽。確認歌手同歌曲版本，尤其係現場錄音同混音版。
  5. 撳 Use Selected Lyrics 套用。

部分服務需要認證資料。LRCLIB 支援同步歌詞同純文字歌詞。網上搜尋需要網絡連線。

同步歌詞同純文字歌詞

同步歌詞有時間標記，話畀播放器知每行幾時開始。純文字歌詞就冇時間。如果睇到文字但唔跟住歌曲走，檢查結果有冇時間標記。你可以喺歌詞編輯器加入時間。

保留本機副本

用 LRC → Save As… 將歌詞儲存到你揀嘅位置。要保留讀音、卡拉 OK 時間或者格式，就用 .lrcx。記住確認儲存位置，方便之後搵返。

振假名同讀音

歌詞讀音輔助

振假名係顯示喺日文歌詞旁邊嘅細字讀音。羅馬字就用拉丁字母顯示讀音。LRCX 讀音註解亦可以保留你親自寫嘅讀音。

選擇讀音顯示

  1. 開啟 Settings → Lyrics。
  2. 一般預設值揀 Global，目前檔案揀 Local (File)。
  3. 開啟 Show furigana、Show romaji 或者 All romaji。呢幾個模式唔可以同時使用。
  4. 用 Ruby position 將振假名放喺歌詞上面或者下面。

選擇自動分析器

分析器要求
Yomi線上日文讀音服務，需要網絡連線。
MeCab選用本機分析器，需要 fugashi 同另外安裝嘅字典。

分析器選項喺歌詞設定入面。所需套件資料可以喺 Settings → Dependencies 睇到。

產生同修正讀音

開啟 LRC → Edit Lyrics → Generation，揀 Generate readings for all lyrics 或者 Generate For This Timestamp。人名、特別寫法同文字遊戲可能會讀錯，儲存之前要檢查。

要保留自己寫嘅讀音，用 {base|reading}，例如 {君|きみ}。詳情見 LRCX 參考。

編輯同校時

改好歌詞，跟返音樂

載入歌曲，再揀 LRC → Edit Lyrics。大幅更改時間之前，先另外儲存一份副本。

編輯歌詞行

喺 Lyrics 分頁揀一行，然後修改文字。用 + Add Line、Delete Line、Move Up 同 Move Down 管理文件。支援粗體、斜體、刪除線、底線同 Quote 格式。

設定逐行時間

  1. 揀要校時嗰行。
  2. 用編輯器嘅播放控制搵出嗰行開始嘅位置。Waveform 可以幫你睇音訊波形。
  3. 嗰行開始嗰刻撳 Mark Playback Time。編輯器會更新時間，再跳去下一行。如果調校嘅係暫存波形標記，就撳 Commit 套用。
  4. 再播一次，確認歌詞跟得啱。

固定時間差可以用 Shift Timing… 調整；用 Validate Timing 檢查時間問題。大範圍移動之前，先試一小段。

卡拉 OK 分段校時

喺 卡拉 OK（Karaoke） 分頁用 Automatic Separation 準備分段邊界，檢查之後揀 Apply Separation。逐段用 Mark Playback Time [F] 記錄時間。自動分段唔保證時間準確，要再聽一次確認。

原始碼同儲存

Source 分頁會顯示有時間嘅歌詞原文。Refresh Source 同 Reload from Source 用嚟喺結構化編輯器同原文之間同步。重新載入可能取代修改，之前要先儲存副本。

用 .lrcx 儲存先可以保留 LRCX 功能。語法同例子見 LRCX 參考。

LRCX 參考

進階歌詞檔實用指南

LRCX 喺 LRC 基礎上加入卡拉 OK 分段時間、讀音註解同文字格式。普通 LRC 檔一樣用得。

時間標記

[00:12.500]The line begins here
[00:16.000]<00:16.000>One <00:16.500>word <00:17.000>at a time

方括號標示一行嘅開始時間；尖括號標示卡拉 OK 分段嘅開始時間。時間用分鐘、秒同毫秒表示。

讀音註解

[00:12.500]{君|きみ}の声

| 前面係原文，後面係讀音。

格式同顯示行

語法效果
**bold**粗體
*italic*斜體
~~text~~刪除線
<u>text</u>底線
{\n}喺同一個時間行入面另開一個顯示行。
> text緊接行時間標記後面使用，會顯示成引用段落。
[00:12.500]**First row**{\n}Second row
[00:16.000]> A quoted lyric

換行標記係實際文字 {\n}，唔係新時間標記。編輯器入面用 Insert Newline {\n}。

歌曲資料同相容性

[ar:Artist]
[ti:Song title]
[al:Album]

要保留進階功能，用 .lrcx 副檔名。其他播放器未必支援呢啲擴充；要兼容其他播放器，可以另外保留普通 LRC 副本。

完整格式規格見專案嘅 LRCX_SPEC.md。可能需要 Markdown 閱讀器。

自訂設定

整到易睇又好用

外觀同背景

開啟 Settings → Appearance，揀淺色或者深色主題、更改重點色，同埋儲存、匯入或者匯出主題。進階色彩控制可以逐項調校介面顏色。

喺 Settings → Background 揀封面來源或者自訂背景資料夾，再調校背景效果。如果歌詞唔易睇，先試用簡單背景。

歌詞排版

喺 Settings → Lyrics 揀精簡或者捲動顯示、書寫方向、對齊、字型同讀音。自動捲動會跟時間標記；連續捲動就獨立移動。捲動行為決定點樣令目前歌詞保持可見。

全域定係個別檔案？ 平時嘅偏好用 Global。如果得一首歌唔同，就檢查 Local (File)。

卡拉 OK 外觀

喺 Settings → Karaoke 自訂卡拉 OK 顯示。逐字進度要歌詞檔有分段時間；外觀設定唔會幫你加入缺少嘅時間。詳情見編輯同校時。

選用功能

額外設定同控制可能由外掛提供，包括夥伴功能同外部整合。開啟 Settings → Plugins 睇你安裝咗邊啲外掛同佢哋嘅設定。

外掛程式

管理選用功能

啟用同設定

  1. 開啟 Settings → Plugins。
  2. 按名稱搵外掛，閱讀介紹。
  3. 用 Enabled 核取方塊更改啟用狀態。核心外掛唔可以停用。
  4. 如果有 Settings 按鈕，就用佢設定外掛。

部分更改可能要重新啟動程式。如果套用之後仲未見到預期控制，重新啟動 LRCPlus。

所需套件同載入錯誤

外掛可能需要額外套件。用外掛嘅 Dependencies 按鈕，或者開啟 Settings → Dependencies 睇資料。載入失敗嘅外掛可能喺設定項目顯示錯誤，可以用嚟搵出缺少或者衝突嘅要求。

加入外掛

安裝方法視乎外掛同發行版本，請跟作者嘅安裝指示。原始碼專案會由 plugins 資料夾尋找外掛；唔好假設每個封裝版本都有相同嘅可寫位置。

開發者可以睇獨立嘅外掛 API 文件。可能需要 Markdown 閱讀器。

疑難排解

由見到嘅症狀開始

播放冇聲

  1. 檢查有冇播放緊，同埋係咪靜音。
  2. 檢查播放器音量同 Windows 音量混音器。
  3. 喺 Settings → Playback 試揀 System Default 輸出裝置。
  4. 試另一個確定正常嘅音訊檔，睇吓係咪得一首歌有問題。

歌詞冇顯示

切換去 Lyrics。用 Ctrl + L 直接開歌詞，或者用 LRC → Search Lyrics。檢查檔名同 Settings → Files 嘅搜尋資料夾。如果 LRC 同 LRCX 都有，先檢查優先使用嘅 LRCX。

歌詞時間唔啱

確認歌詞同錄音版本相符。現場版、混音版同唔同前奏通常有唔同時間。檢查檔案有冇時間標記。固定差距用 Shift Timing…；如果差距會隨歌曲位置改變，就逐行修正。

讀音缺少或者唔啱

檢查 Settings → Lyrics 嘅讀音模式，包括 Local (File)。Yomi 需要連線；MeCab 需要本機套件同字典。檢查自動結果；要指定讀法，可以自己寫 LRCX 讀音註解。

外掛用唔到

喺 Settings → Plugins 睇啟用狀態同載入錯誤。缺少套件就檢查 Dependencies。有需要嘅話，更改設定之後重新啟動。

回報問題

提供 Settings → About 入面嘅 LRCPlus 版本、Windows 版本、重現步驟、預期行為同實際結果。講埋其他歌曲有冇同樣問題，同有冇用選用外掛。如果有助解釋時間或者顯示問題，可以附上一小段歌詞例子。

介面導覽

跟住編號認識實際程式畫面

跟住畫面編號搵手冊提到嘅控制。撳藍色編號就會跳去解釋。截圖係實際原始碼版本，使用示範歌詞同獨立設定；外掛同主題可能會加入或者更改控制。

播放器同歌詞工作區

  1. 音樂庫工作區。 返回音樂收藏；Lyrics 會帶你返歌詞畫面。
  2. LRC 選單。 撳 LRC 編輯目前歌詞。箭嘴會開啟 Search Lyrics、Save As 同其他歌詞操作。
  3. 歌詞顯示。 同步歌詞喺呢度顯示。Settings → Lyrics 控制顯示模式、字型、對齊同讀音。
  4. 歌詞行清單。 展開或者收起有時間嘅歌詞行。展開後撳一行，就會跳去嗰個時間。
  5. 進度列。 移動到其他播放位置。未載入音訊時，長度同移動範圍都係零。
  6. 播放或者暫停。 暫停或者繼續播放。旁邊按鈕可以停止、跳五秒或者轉歌。
  7. 音量。 調校音量；Mute 會靜音，但保留已儲存嘅音量值。

音樂庫工作區

  1. 搜尋音樂庫。 篩選音樂庫清單，唔會改檔案。
  2. 音樂庫。 加入資料夾之後，歌曲會喺呢度顯示。連撳兩下播放；右擊欄標題管理顯示嘅欄位。
  3. 開啟檔案。 Open Audio 載入音訊；Add to Queue 加入佇列；Open Lyrics 附加歌詞檔。
  4. 設定。 開啟偏好設定。可以用分類清單同設定搜尋搵選項。
  5. 播放控制。 兩個工作區都有播放控制。喺 Play from 揀 Library 或者 Queue / Playlist。

歌詞編輯器

  1. 編輯器工作區。 切換 Lyrics、Generation、Source、Share 同 Advanced。選用外掛可以加入其他工作區。
  2. 有時間嘅歌詞行。 揀要編輯嘅行。Search、Previous、Next 同排序選項可以幫你瀏覽長文件。
  3. 記錄播放時間。 將目前播放時間記入所選行，再去下一行。校時之前先載入音訊。
  4. 儲存。 Save 儲存修改並保持編輯器開啟；Save & Close 儲存後關閉。冇修改時 Save 會停用。

設定視窗

  1. 設定分類。 揀一個分類。分類上面嘅搜尋欄可以按名稱搵設定。
  2. 無縫播放。 預先緩衝下一首歌。需要 FFmpeg，同正常速度及音高；由下一首生效。
  3. 輸出裝置。 揀輸出裝置。System Default 跟隨系統選擇。

設定參考

選項、出廠預設同適用範圍

呢度列出播放器同歌詞控制嘅出廠預設值。已儲存偏好、設定預設組合或者個別檔案覆寫可能令實際值唔同。開啟 Settings 再揀對應分類。如果知選項名稱，可以用設定搜尋。

全域設定同檔案覆寫

大部分分類套用到全個程式。 Lyrics → Global 提供歌詞顯示預設值，而 Lyrics → Local (File) 會覆寫目前檔案嘅指定選項。冇覆寫嘅檔案會沿用全域值。自動日文分析器係 只限全域 嘅選項。卡拉 OK 外觀同播放偏好亦會套用到全個程式。

如果得一個檔案睇落唔同，先檢查 Local (File)。檔案覆寫係跟檔案路徑，唔同於 LRCX 文件內儲存嘅讀音、時間標記同格式。

實作教學

三個由頭做到尾嘅小任務

為第一首歌校時

  1. 開啟音訊，再開編輯器，按文件順序加入歌詞行。
  2. 揀第一行，用編輯器控制開始播放。
  3. 唱到嗰行開頭嗰刻，撳 Mark Playback Time。編輯器會記錄時間，再去下一行。
  4. 重複以上步驟，再聽返，修正太早或者太遲嘅標記。
  5. 用 Validate Timing 檢查結果，再儲存副本。

先試三四行。逐段卡拉 OK 校時係另一個步驟，喺選用 Karaoke 分頁進行。

修正遲咗兩秒嘅歌詞

如果歌詞每次都喺歌手開始唱之後兩秒先出現，就將時間標記提早兩秒。

  1. 先儲存備份。
  2. 開啟 Shift Timing…，揀要套用嘅範圍，例如全部行。
  3. 按對話框顯示嘅單位輸入 −2 秒或者 −2000 毫秒。正數會將歌詞延後。
  4. 喺歌曲開頭同結尾聽吓。如果差距會變，就逐行修正，或者搵返啱錄音版本嘅歌詞。
  5. 檢查同儲存。編輯中可以用復原取消移動。

Shift Timing 改嘅係時間標記，獨立嘅歌詞偏移值唔會改。移前兩秒之後，[00:12.000] 會變成 [00:10.000]。

加入自訂振假名

  1. 開啟歌詞文件，切換去 Source。
  2. 先備份，再用 {base|reading} 包住一個詞。
  3. 例如將 [00:12.500]君の声 改成 [00:12.500]{君|きみ}の声。
  4. 用 Reload from Source 套用到結構化編輯器。
  5. 開啟 Show furigana，檢查之後儲存成 .lrcx。

自己寫讀音可以修正人名同特別讀法。

Play from 設為 Queue / Playlist 時使用嘅歌曲清單。
讀音服務（Reading provider）
產生發音或者羅馬字讀音嘅元件。
ReplayGain
用嚟平衡播放音量嘅響度同峰值資料。
羅馬字（Romaji）
用拉丁字母表示嘅日文讀音。
讀音註解（Ruby）
包括原文同讀音嘅註解，LRCX 寫法係 {base|reading}。
分段（Segment）
有獨立時間嘅單詞或者更短歌詞片段。
時間標記（Timestamp）
歌曲入面嘅位置，代表一行或者卡拉 OK 分段嘅開始。
翻譯服務（Translation provider）
產生譯文而唔係發音讀音嘅元件。

Anki Flashcards

內附外掛指南

揀歌詞單詞，匯出成 Anki 用嘅 TSV 記憶卡。

設定

揀歌詞單詞、檢查記憶卡內容，再匯出 Anki 用嘅 TSV 檔。

使用功能

載入歌詞之後用外掛嘅記憶卡操作。匯入 Anki 之前檢查匯出欄位。呢個功能會匯出檔案，唔會自動改牌組。

要求

呢個外掛嘅資訊清單冇列出額外套件。

喺 Settings → Plugins 檢查載入錯誤，同喺 Settings → Dependencies 睇套件狀態。淨係裝 Python 套件唔代表已設定好外部服務。

Cantonese Readings

內附外掛指南

Plugin API v2 粵語讀音：透過 PyCantonese 提供粵拼同耶魯拼音。

設定

安裝 Settings → Dependencies 列出嘅 PyCantonese 套件。

使用功能

外掛會註冊粵拼同耶魯讀音服務。粵語內容要揀對應讀音模式。長歌詞可能分析得慢；出現提示時，可以揀即刻產生，或者唔產生就載入。

要求

  • pycantonese>=3.4,<4

喺 Settings → Plugins 檢查載入錯誤，同喺 Settings → Dependencies 睇套件狀態。淨係裝 Python 套件唔代表已設定好外部服務。

Discord Rich Presence

內附外掛指南

用歌曲資料、歌詞同專輯封面自訂 Discord 活動。

設定

開啟 Discord，再喺 Settings → Plugins → Discord Rich Presence → Settings 設定。

使用功能

揀 Discord 活動顯示嘅歌曲資料、歌詞同封面。如果冇活動，檢查 Discord、外掛啟用狀態同所需套件。

要求

  • pypresence>=4.6,<5
  • requests>=2,<3
  • mutagen>=1,<2

喺 Settings → Plugins 檢查載入錯誤，同喺 Settings → Dependencies 睇套件狀態。淨係裝 Python 套件唔代表已設定好外部服務。

喺 Settings → Plugins 檢查載入錯誤，同喺 Settings → Dependencies 睇套件狀態。淨係裝 Python 套件唔代表已設定好外部服務。

Lyrics Translator

內附外掛指南

用選用離線 Argos，或者 Azure、Google Cloud、DeepL 同 MyMemory 翻譯歌詞行。

設定

啟用外掛，再喺編輯器 Translations 分頁揀服務。

使用功能

Argos 需要選用本機套件同語言模型。雲端翻譯需要服務連線同認證資料。儲存之前要檢查結果並套用到文件。

要求

  • argostranslate==1.11.0 (optional)

喺 Settings → Plugins 檢查載入錯誤，同喺 Settings → Dependencies 睇套件狀態。淨係裝 Python 套件唔代表已設定好外部服務。

yt-dlp Audio Import

內附外掛指南

搜尋 YouTube 或者由網址匯入音訊同字幕，亦可選擇同步歌詞同 MusicBrainz 專輯封面。

設定

開啟 Plugins → Search and import audio…，揀結果或者輸入支援網址。

使用功能

下載之前檢查匯入選項同目的地。外掛可以匯入音訊同字幕，並選擇同步歌詞同專輯封面。匯入失敗就檢查設定同套件錯誤。

要求

  • yt-dlp[default]>=2026.3.3
  • mutagen>=1,<2

喺 Settings → Plugins 檢查載入錯誤，同喺 Settings → Dependencies 睇套件狀態。淨係裝 Python 套件唔代表已設定好外部服務。

Karaoke Screen

內附外掛指南

全螢幕歌詞，同選用 MIDI 音高指引。

設定

載入 Karaoke Screen 之後，用播放器嘅 Karaoke Screen 按鈕開啟全螢幕歌詞。外掛設定名稱係 Karaoke Game.

使用功能

外掛提供全螢幕歌詞同選用 MIDI 音高指引。音高指引需要合適 MIDI 資料；歌詞時間同 MIDI 音符係分開輸入嘅。

要求

呢個外掛嘅資訊清單冇列出額外套件。

喺 Settings → Plugins 檢查載入錯誤，同喺 Settings → Dependencies 睇套件狀態。淨係裝 Python 套件唔代表已設定好外部服務。
