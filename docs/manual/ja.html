このマニュアルは LRCPlus の現在のソース版にある操作を説明しています。ビルドや有効なプラグインによって使える機能は異なります。 Settings → Lyrics のようなメニュー表記は、アプリ内で選ぶ項目を表します。

はじめに

LRCPlus で最初の曲を聴く

LRCPlus は音楽に合わせて同期歌詞を表示します。読みの補助やカラオケのタイミングも利用できます。音声ファイルが 1 つあれば始められます。

最初の曲を再生する

  1. LRCPlus を起動します。セットアップウィザードが表示された場合は、案内に従ってください。
  2. Open → Open Audio… を選ぶか、Ctrl + O を押し、音声ファイルを選びます。
  3. Play で再生と一時停止を切り替えます。
  4. Lyrics で歌詞画面に、Library で音楽ライブラリに切り替えます。

歌詞を追加する

対応する歌詞ファイルがあれば、Open → Open Lyrics…（Ctrl + L）で開きます。ない場合は LRC → Search Lyrics でオンライン検索します。詳しくは歌詞を探すをご覧ください。

ファイル名をそろえてみましょう。 次のファイルを同じフォルダーに置きます： Song.mp3 と Song.lrc （または Song.lrcx）。両方の歌詞形式がある場合、LRCPlus は LRCX を優先します。

次にできること

  • ライブラリに音楽フォルダーを追加する。
  • ふりがなやローマ字を表示する。
  • 歌詞の行を修正する。

Settings → General → Relaunch Wizard で、セットアップウィザードを開き直せます。

音楽と再生

ライブラリ、キュー、再生コントロール

音楽ライブラリを作る

  1. Library に切り替えます。
  2. Add Music Folder をクリックし、音楽が入ったフォルダーを選びます。
  3. 音楽フォルダー内のファイルを変更したら、Rescan で反映します。

Remove Folder で、ライブラリの対象フォルダーを管理できます。

キューを使う

Open → Add to Queue…（Ctrl + Shift + O）でファイルを追加します。再生元には Library と Queue / Playlist があります。意図しない曲が再生される場合は、この選択を確認してください。

音声ファイルをキューにドロップすると末尾に追加します。ライブラリの選択曲を右クリックすると Play now、Play next、Add to queue を使えます。Play now は現在のキュー項目の後ろに挿入して再生し、Play next は次の再生用に挿入します。Add to saved playlist で新規プレイリストの作成や既存の一覧への追加ができます。曲のメニューから保存場所を開く、パスや名前をコピーする、プロパティを見る操作もできます。

再生の設定

Settings → Playback で出力デバイス、曲／アルバム単位のシャッフル、再生後の動作（次の曲、停止、全曲リピート、1 曲リピート）を選べます。出力先に迷ったら、System Default を選んでください。

再生や画面切り替えをすばやく行うには、キーボードショートカットをご覧ください。

検索とお気に入り

曲名・アーティスト・アルバムで検索するか、ローカル歌詞検索で索引済みの歌詞を探します。通常の曲情報検索で結果がない場合、4 文字以上の単語は 1 文字の不足・追加・置換・隣接文字の入れ替えも候補になり、Close matches と表示されます。短い単語、数字、歌詞検索は入力どおりに検索します。

再生中の曲やライブラリのハートを押すとお気に入りになります。ライブラリとキューの右クリックメニューでは選択曲をまとめて変更できます。Favorites フィルターは両方の検索方式と併用できます。お気に入りはファイルパスで保存され、再スキャン後も残りますが、移動先には自動で引き継がれません。

曲の取り込みと一覧からの削除

音声ファイルやフォルダーをメイン画面にドロップするとバックグラウンドで取り込みます。ドロップ先の表示で Library への追加かキュー末尾への追加かを確認できます。ライブラリへの取り込み後は Library が開き、追加曲が選択されます。曲を表示するため検索や Favorites が解除されることがあります。

曲やアルバムを右クリックして Remove from library を選ぶと、ディスク上のファイル、キュー、お気に入り、保存済みプレイリストを保ったまま一覧から削除します。再スキャンや再起動でも除外は続きます。除外した音声ファイルを再びライブラリにドロップすると復元できます。

重み付きシャッフル

Settings → Playback → Shuffle で Weighted tracks を選び、下部の Shuffle を有効にします。Favor favorite songs はお気に入りの重みを 2 倍にします。Favor songs not played recently は最近聴いた曲の重みを通常の 20% から始め、14 日かけて元に戻します。どの対象曲にも選ばれる可能性があります。

再生時期を使うのは統計記録が有効な間だけです。無効でもお気に入りの重みは利用できます。明示的にキューに指定した曲は優先されます。

下部には曲のリピート、回数指定、A-B、速度、音程もあります。曲ごとのマーカーはアプリ終了まで保持し、スリープタイマーを優先します。

リピートと練習

曲全体や一節を繰り返し、歌いやすい速さと音程に調整する

曲全体を繰り返す

プレーヤー下部の Shuffle の隣にある Repeat を開きます。Repeat off は選択中のライブラリやキューを一度再生し、Repeat all はその一覧を繰り返し、Repeat current track は現在の曲を繰り返します。

  1. 練習する曲を読み込みます。
  2. Play current track N times... を選び、合計回数を 2～999 で指定します。
  3. 合計 3 回なら 3 を入力します。途中から指定しても、現在の再生が 1 回目に含まれます。
  4. Repeat: 1/3 などの表示で進行を確認します。最後の再生後は通常どおり次へ進みます。

Stop、曲の変更、別のリピートモードの選択で回数指定は解除されます。回数指定は現在のセッションだけで有効です。

難しい一節を繰り返す

  1. 一節の開始位置へ移動し、A-B → Set A at current position を選びます。
  2. 終了位置まで再生または移動し、Set B and loop を選びます。B は A より 0.1 秒以上後に設定します。
  3. 再生位置が A に戻ります。一時停止中なら Play を押してください。マーカー設定だけでは再生は始まりません。
  4. Clear A-B loop で通常再生に戻ります。A を設定し直すと B も解除されます。

シークバーに両端の旗と範囲が表示されます。曲ごとのマーカーは LRCPlus を終了するまで保持され、別の曲から戻ると復元されます。同じファイルのキュー項目はマーカーを共有します。Stop では保持し、Clear は現在の曲だけを解除します。音声の長さが変わると、無効な境界は解除されることがあります。

速さと音程を変える

下部の Pitch から再生速度と音程を調整できます。速い一節は速度を落とし、歌うキーは音程で変えます。音程表示の下には 1 オクターブ下で歌う場合の差も表示されます。たとえば +4 半音は、1 オクターブ下では元の曲から −8 半音です。

速度と音程は保存される共通の再生設定です。Lyrics → Local (File) の表示設定とは別です。原音に戻すには速度 100%、音程 0 半音にします。

練習機能を組み合わせる

曲全体の回数指定を使う前に A-B 範囲を解除してください。範囲を設定している間はクロスフェードと次曲の先読みが停止します。スリープタイマーはループやリピートより優先されます。ギャップレス再生とクロスフェードには FFmpeg、通常速度、音程変更なしが必要です。詳しくは再生設定をご覧ください。

スリープタイマー

指定時間後や曲の終わりに一時停止する

タイマーを開始する

  1. プレーヤー下部の Sleep を押します。
  2. 15、30、45、60、90 分、または Custom… で 1～720 分を選びます。
  3. When time is up で Pause immediately（すぐ一時停止）か Finish the current song（再生中の曲を最後まで）を選びます。
  4. Start timer を押します。ダイアログを閉じてもタイマーは続きます。

時間を指定せず、読み込み中の曲の終わりで止めるには At the end of this song を選びます。

確認・延長・解除

Sleep ボタンに残り時間が表示されます。もう一度開くと状態と終了予定時刻を確認できます。Add 5 minutes は動作中のカウントダウンを 5 分延長します。新しい時間を指定して Replace timer を押すと置き換えます。Cancel timer は再生を止めずにタイマーを解除します。

一時停止中もカウントダウンは続きます。Stop はタイマーを解除します。最後に使った時間と終了時の動作は保存されますが、動作中のタイマーはアプリ終了時に解除されます。

曲の終わりを待つ動作

Finish the current song は時間切れ時点で再生している曲の終わりを待ち、リピートや次曲に進む前に一時停止します。待機中は Sleep: song と表示されます。A-B ループよりも優先され、曲を最後まで再生します。

待機中に曲をスキップするとタイマーは終了し、選択先の曲は停止したままになります。再開するには Play を押します。たとえば 30 分で曲の終わりを待つ設定では、30 分を超えることがあります。時間どおりに止めるには Pause immediately を選んでください。

リスニング統計

この端末での再生時間と再生回数を確認する

記録するかを選ぶ

Statistics または Ctrl + 3 を開きます。この画面か Settings → General → Listening history の Record listening statistics on this device で記録を有効にします。新規インストールでは無効です。更新時は既存の設定を保持します。

有効にした後の再生から記録します。Recent やライブラリから過去の履歴を再構築することはありません。

統計を見る

Today、Last 7 days、Last 30 days、All time で期間を選びます。再生時間、回数、異なる曲数、日ごとの推移、曲・アーティスト・アルバムの上位 100 件を確認できます。All time のグラフは直近 365 日、合計値は記録済みの全期間が対象です。

記録される時間と回数

実際に聴いた時間を記録するため、高速再生でも 20 秒聴けば約 20 秒です。一時停止、シークで飛ばした区間、バッファ待ち、システムのスリープ、プレーヤーのミュートや音量ゼロは加算しません。

1 回の再生で、30 秒または曲の長さの半分のうち短い方まで聴くと、再生回数を 1 回加算します。一時停止からの再開やシークは同じ再生として扱い、リピートや最初からの再生は新しい再生になります。短時間だけ聴いた場合、時間だけ増えて回数は増えないことがあります。

履歴を管理する

履歴はこの端末に保存されます。記録を無効にしても合計値は残ります。Clear statistics… は確認後に履歴を削除し、音楽、プレイリスト、Recent は保持します。ファイルパスで識別するため、曲を移動すると別の項目になります。

重み付きシャッフルが再生時期を利用するのは記録が有効な間だけです。設定のエクスポートには記録の有効・無効を含みますが、履歴本体は含みません。

設定のインポート・エクスポートと初期化

環境間で設定を移し、適用前に工場出荷時の設定を確認する

設定を書き出す

  1. Settings → Advanced を開きます。
  2. Export settings… を選び、JSON ファイルを保存します。

未保存の変更も含め、現在表示中の設定を書き出します。外観、保存済みテーマ、再生と歌詞の全体設定、歌詞検索フォルダー、更新設定、プラグイン設定が対象です。

書き出す範囲：ライブラリ、保存済みプレイリスト、履歴、曲ごとの歌詞設定、読み辞書は別に保存されています。このファイルは設定の移行用です。個人の読み辞書には辞書管理画面のエクスポートを使ってください。

読み込んで確認する

  1. Import settings… で書き出した JSON を選びます。無効なファイルにはエラーが表示されます。
  2. 適用前に各タブを確認します。別の PC ではフォルダーパスと音声出力を見直してください。
  3. OK で適用し、Cancel で読み込んだ下書きを破棄します。
  4. プラグイン設定を適用した後は LRCPlus を再起動します。

設定の読み込みでは、別に保存されているライブラリ、プレイリスト、履歴、曲別設定、辞書は保持されます。

工場出荷時の設定を確認する

Advanced の Restore factory defaults… を選び、各タブを確認してから OK で適用、Cancel で破棄します。保存済みテーマ、フォルダー、プラグイン設定、ライブラリ、プレイリスト、履歴、曲別設定、読み辞書は保持します。

現在の既定設定はダークの Nordic Frost、アクセント #88c0d0、背景ぼかしなし、プレイリスト復元ありです。更新の自動確認と統計記録は無効です。読み辞書を初期の内容に置き換える場合は、辞書管理画面の Manage → Restore factory dictionaries… を使い、両方の画面で OK を押してください。

歌詞を探す

ファイルを読み込む、または対応する歌詞を探す

ローカルの歌詞を開く

曲を読み込み、Open → Open Lyrics… で .lrc または .lrcx を選びます。音声ファイルと同じ名前にすると自動検出しやすくなります。検索先の追加は Settings → Files で行います。

オンラインで検索する

  1. 歌詞を探したい曲を読み込みます。
  2. LRC → Search Lyrics を選びます。
  3. 検索条件を確認し、Search をクリックします。
  4. 結果を選んでプレビューを確認します。特にライブ音源やリミックスでは、アーティストと曲のバージョンが一致するか確認してください。
  5. Use Selected Lyrics をクリックして適用します。

認証情報が必要なプロバイダーもあります。LRCLIB は同期歌詞とプレーンテキスト歌詞に対応しています。オンライン検索には接続が必要です。

同期歌詞とプレーンテキスト歌詞

同期歌詞には、各行の開始時刻を示すタイムスタンプがあります。プレーンテキスト歌詞には時刻情報がありません。文字が表示されても曲に追従しない場合は、タイムスタンプの有無を確認してください。時刻は歌詞エディターで追加できます。

ローカルに保存する

LRC → Save As… で保存先を選びます。読み、カラオケの時刻、書式を保持する場合は .lrcx で保存してください。後から見つけられるよう、保存先も確認しましょう。

ふりがなと読み

歌詞を読むための補助機能

ふりがなは、日本語の歌詞に添える小さな読みです。ローマ字表示では、読みをラテン文字で表示します。LRCX に保存したルビを使うと、指定した読みを表示できます。

読みの表示方法を選ぶ

  1. Settings → Lyrics で Global または Local (File) を選び、Readings を開きます。
  2. Lyric layers の Lyrics、Romaji、Translation、Furigana を個別に切り替えます。少なくとも 1 つは有効にします。
  3. ドラッグ、Move up / Move down、または選択後に Alt + ↑ / ↓ で順序を変えます。

Romaji は Lyrics と併用すると小さく、単独では通常サイズになります。Translation はファイル内の翻訳行を表示するだけで、翻訳を生成しません。順序と表示は Compact、Scrolling、Floating Lyrics に反映され、一時停止中も更新されます。ローマ字だけを表示するには Romaji を有効にして他を無効にします。

自動解析器を選ぶ

解析器必要条件
Yomi日本語の読みを生成するオンラインサービスです。インターネット接続が必要です。
MeCabオプションのローカル解析器です。fugashi と辞書を別途インストールする必要があります。

解析器は歌詞設定で選べます。依存パッケージの情報は Settings → Dependencies で確認してください。

読みを生成して修正する

LRC → Edit Lyrics を開き、Generation タブで Generate readings for all lyrics（全歌詞）または Generate For This Timestamp（この時刻のみ）を選びます。人名、特殊な表記、言葉遊びなどは読みが誤ることがあるため、保存前に確認してください。

指定した読みを LRCX に保存するには、{base|reading} の形式を使います。例：{君|きみ}。詳しくは LRCX リファレンスをご覧ください。

個人の読み修正を保存する

  1. Settings → Lyrics → Global → Readings → Manage reading dictionaries… を開きます。
  2. Manage → New dictionary…、Add entry の順に選びます。例として Reading に あす、Word に 明日、Reading type に Japanese furigana を指定します。
  3. 通常は Whole word を使います。Inside words は大きな単語の一部にも意図的に一致させる場合に使います。
  4. 辞書管理画面で OK、Settings でも OK を押して保存します。Cancel は対応する下書きを破棄します。

チェックのある辞書が有効です。一致する最長の語が優先され、同じ種類の同じ語なら先頭の有効な辞書を使います。Manage で優先順位を変更できます。曲に保存したルビは辞書より優先されます。翻訳やカラオケの時刻は変更しません。

日本語ふりがな、標準中国語ピンイン、韓国語ローマ字、広東語 Jyutping・Yale に対応します。日本語は仮名で入力し、Romaji が変換します。Manage から JSON/TSV や Google 日本語入力の辞書を書き込め、選択辞書を JSON/TSV で書き出せます。インポートは別の辞書を追加します。新規環境には Japanese song readings として 私 → わたし、君 → きみ、時 → とき が含まれます。

歌詞の編集とタイミング

歌詞を直して音楽に合わせる

曲を読み込み、LRC → Edit Lyrics を選びます。大きくタイミングを変更する前に、別名でコピーを保存してください。

編集内容のプレビューと波形操作

Lyrics で行を選び、入力欄の下にある Live preview で書式、読み、再生中のハイライトを確認します。長い歌詞を編集するときは Expand text を使います。

Lyrics または Karaoke で Waveform を表示します。波形を移動・拡大し、Fit line で選択行に合わせ、All audio で曲全体を表示できます。歌詞のタイミングを変えずに再生位置を移動するには、Ctrl を押しながら波形を左クリックします。どのタブでも F1 で Shortcuts を開いて検索できます。

曲を読み込んでいない場合は、歌詞エディターで Create New LRCX または Open LRCX を選びます。未保存の下書きに復元用コピーがある場合は、開始画面の Recover Draft から開き、編集が済んだら保存します。

歌詞の行を編集する

Lyrics タブで行を選び、本文を編集します。行の管理には + Add Line、Delete Line、Move Up、Move Down を使います。太字、斜体、取り消し線、下線、Quote（引用）の書式も使えます。

行のタイミングを設定する

  1. 時刻を設定する行を選びます。
  2. エディターの再生コントロールで、行が始まる位置を探します。 Waveform を使うと音声を波形で確認できます。
  3. 行の開始位置で Mark Playback Time を使います。選択行の時刻が更新され、次の行に進みます。波形上の仮マーカーを調整した場合は、Commit で時刻を適用します。
  4. もう一度再生して、歌詞が音楽に合っているか確認します。

Shift Timing… で時刻をまとめてずらし、Validate Timing で問題を確認できます。広い範囲に適用する前に、短い区間で試してください。

カラオケ区間のタイミングを設定する

Karaoke タブで Automatic Separation を使って区切りを用意し、内容を確認して Apply Separation で適用します。各区間の時刻には Mark Playback Time [F] を使います。必ず聴き直してください。自動分割だけでは、正確な時刻になるとは限りません。

ソースと保存

Source タブでは時刻付きの歌詞を直接確認できます。Refresh Source でエディターの内容をソースに反映し、Reload from Source でソースをエディターに読み込みます。再読み込みで編集が置き換わることがあるため、先にコピーを保存してください。

LRCX の機能を保持するには .lrcx で保存します。構文と例は LRCX リファレンスをご覧ください。

画面上で読みを修正する

Lyrics タブで単語の上の読み、または小さなプラスを押して編集します。Enter で適用、Escape で中止します。隣接する部分をまとめるには、単語をクリックして隣を Shift クリックし、右クリックから Combine reading を選びます。1 語を選んで Split reading... を選ぶと、本文の分割位置と両方の読みを確認できます。空白や改行をまたぐ結合はできません。

歌詞本文、時刻、書式、翻訳行を保ち、Undo/Redo に対応します。指定した読みと単語のまとまりを残すには LRCX で保存します。

複数行の編集とタイミング確認

Shift/Ctrl で複数行を選び、Selected Lines… から時刻の移動、書式、行の移動、削除を行います。プレビューが出る場合は内容を確認してください。Split at Cursor… は現在行を分割し、Merge with Next… や Merge Selected… は空白、改行、区切りなしで結合します。

本文の修正では変更していない部分の時刻を保ちます。時刻付きの部分の途中で分割すると新しい境界を推定するため、強調された部分を聴き直してください。Undo/Redo で編集と行選択を戻せます。

LRCX リファレンス

拡張歌詞ファイルの実用ガイド

LRCX は LRC を拡張し、カラオケ区間の時刻、ルビ、文字書式を扱えます。通常の LRC ファイルも使えます。

タイムスタンプ

[00:12.500]ここから行が始まります
[00:16.000]<00:16.000>一語 <00:16.500>ずつ <00:17.000>表示します

角括弧のタイムスタンプは行の開始時刻、山括弧のタイムスタンプはカラオケ区間の開始時刻です。分、秒、ミリ秒で指定します。

ルビ

[00:12.500]{君|きみ}の声

| の前が歌詞の本文、後が読みです。

書式と表示行

構文効果
**bold**太字
*italic*斜体
~~text~~取り消し線
<u>text</u>下線
{\n}同じ時刻の行内で、表示上の行を追加します。
> text行のタイムスタンプの直後に置くと引用になります。
[00:12.500]**1 行目**{\n}2 行目
[00:16.000]> 引用した歌詞

表示上の改行は、文字列 {\n} で表します。新しいタイムスタンプではありません。エディターでは Insert Newline {\n} を使います。

メタデータと互換性

[ar:アーティスト]
[ti:曲名]
[al:アルバム]

拡張機能を保持するには .lrcx で保存します。他の歌詞プレーヤーでは解釈できない場合があるため、互換性が必要なら通常の LRC も残してください。

完全な形式仕様は、プロジェクトの LRCX_SPEC.md を参照してください（Markdown を読めるアプリが必要な場合があります）。

カスタマイズ

読みやすく、使いやすいプレーヤーにする

外観と背景

Settings → Appearance → Theme で Light、Dark、Use Qt Theme を選びます。Qt モードは既定のウィジェットスタイルとシステム配色を使います。Light や Dark に戻すとカスタム色を再び利用できます。Appearance からテーマの保存、インポート、エクスポートもできます。

Settings → Background でアートワークの取得元や背景画像フォルダーを選び、背景の見え方を調整します。歌詞が読みにくい場合は、シンプルな背景から試してください。

歌詞のレイアウト

Settings → Lyrics でコンパクト／スクロール表示、文字方向、配置、フォント、読みを選べます。自動スクロールはタイムスタンプに追従し、連続スクロールは独立して動きます。スクロール動作で、現在の歌詞を表示範囲に保つ方法を選べます。

全体設定とファイル設定 次を使います： Global は通常の設定に使います。1 曲だけ表示が異なる場合は、 Local (File) を確認してください。

カラオケの外観

Settings → Karaoke でカラオケの外観を調整します。単語ごとの進行表示には、歌詞ファイルに区間時刻が必要です。外観設定だけでは時刻情報を追加できません。詳しくは歌詞の編集とタイミングをご覧ください。

オプション機能

コンパニオンや外部連携など、プラグインが設定を追加する場合があります。Settings → Plugins で利用可能なプラグインと設定を確認できます。

プラグイン

オプション機能を管理する

有効化と設定

  1. Settings → Plugins を開きます。
  2. 名前でプラグインを探し、説明を読みます。
  3. Enabled で有効／無効を切り替えます。コアプラグインは無効にできません。
  4. Settings ボタンがある場合は、そのボタンでプラグインを設定します。

変更によってはアプリの再起動が必要です。設定を適用しても目的のコントロールが表示されない場合は、LRCPlus を再起動してください。

依存パッケージと読み込みエラー

追加パッケージが必要な場合は、プラグインの Dependencies ボタン、または Settings → Dependencies で確認できます。読み込みに失敗すると、設定項目にエラーが表示される場合があります。その内容から不足や競合を調べてください。

プラグインを追加する

プラグインは LRCPlus Community Plugins Repository からダウンロードできます。official_community_plugins で利用可能なフォルダーを確認してください。

  1. LRCPlus を終了します。リポジトリの Code → Download ZIP を選び、アーカイブを展開します。
  2. official_community_plugins を開き、必要なプラグインのフォルダーをそれぞれ LRCPlus installation folder\plugins\community\ にコピーします。関連ファイルも含め、フォルダー全体をコピーしてください。
  3. plugins/community/discord_rpc/plugin.py のように、各プラグインのフォルダー直下に plugin.py があることを確認します。リポジトリ全体や official_community_plugins フォルダーをそのまま community に入れないでください。plugins/core は変更・削除しないでください。
  4. LRCPlus を再起動し、Settings → Plugins を確認します。不足するパッケージは Settings → Dependencies からインストールし、案内に従って再起動します。

プラグインは Python コードを実行します。信頼できる配布元のものだけをインストールし、各プラグインの README にある追加の手順にも従ってください。

開発者向けの情報は、別のプラグイン API ドキュメントにあります（Markdown を読めるアプリが必要な場合があります）。

トラブルシューティング

目に見える症状から確認する

音が出ない

  1. 再生中であることと、ミュートになっていないことを確認します。
  2. プレーヤーの音量と Windows の音量ミキサーを確認します。
  3. Settings → Playback で、出力デバイスに System Default を試します。
  4. 正常に再生できる別の音声ファイルを試し、その曲だけの問題か確認します。

歌詞が表示されない

Lyrics に切り替え、Ctrl + L で歌詞ファイルを開くか、LRC → Search Lyrics を使います。ファイル名と Settings → Files の検索先を確認してください。LRC と LRCX が両方ある場合は、優先される LRCX を先に確認します。

歌詞のタイミングが合わない

歌詞が音源と一致するか確認してください。ライブ版、リミックス、イントロの違いで時刻が変わります。タイムスタンプの有無も確認します。全体のずれは Shift Timing… で修正できます。途中でずれが変わる場合は各行を直してください。

読みが表示されない、または正しくない

Settings → Lyrics の読みのモードと、Local (File) の設定を確認します。Yomi は接続、MeCab はローカルのパッケージと辞書が必要です。自動生成結果を確認し、特定の読みが必要な語には LRCX のルビを指定してください。

プラグインが使えない

Settings → Plugins で有効状態と読み込みエラーを確認します。パッケージが不足していれば Dependencies も確認してください。設定変更後、必要に応じて再起動します。

問題を報告する

Settings → About の LRCPlus バージョン、Windows のバージョン、再現手順、期待する動作、実際の動作を記載してください。他の曲でも起きるか、プラグインが関係するかも役立ちます。時刻や描画の問題には、小さな歌詞の例を添えてください。

画面の使い方

実際のアプリ画面を番号付きで案内します

青い番号を選ぶと、対応する説明に移動します。画像はサンプル歌詞と独立した設定を使った実際のソース版です。プラグインやテーマによってコントロールが変わる場合があります。画像内のアプリ表示は英語です。

プレーヤーと歌詞画面

  1. ライブラリ画面。 音楽コレクションに戻ります。Lyrics でこの歌詞画面に戻れます。
  2. LRC メニュー。 LRC をクリックすると現在の歌詞を編集できます。矢印から Search Lyrics、Save As などを開けます。
  3. 歌詞表示。 同期歌詞を表示します。表示モード、フォント、配置、読みは Settings → Lyrics で調整します。
  4. 行の一覧。 時刻付きの行一覧を展開／折りたたみます。展開した一覧の行をクリックすると、その時刻に移動します。
  5. シークバー。 再生位置を移動します。音声がない場合は、再生時間と移動範囲は 0 のままです。
  6. 再生と一時停止。 一時停止／再開します。隣のボタンで停止、5 秒移動、曲の切り替えができます。
  7. 音量。 音量を調整します。Mute では、保存した音量値を変えずに音を消せます。

ライブラリ画面

  1. ライブラリ検索。 ファイルを変更せずにライブラリを絞り込みます。
  2. 音楽ライブラリ。 フォルダーを追加すると曲が表示されます。ダブルクリックで再生し、列見出しの右クリックで表示列を管理できます。
  3. ファイルを開く。 Open Audio で音声を読み込み、Add to Queue でキューに追加し、Open Lyrics で歌詞を付けます。
  4. 設定。 設定画面を開きます。カテゴリー一覧と設定検索から項目を探せます。
  5. 再生コントロール。 どちらの画面でも再生操作ができます。Play from で Library または Queue / Playlist を選んでください。

歌詞エディター

  1. エディターのタブ。 Lyrics、Generation、Source、Share、Advanced を切り替えます。プラグインがタブを追加する場合もあります。
  2. 時刻付きの歌詞行。 編集する行を選びます。長い文書では Search、Previous、Next、並び順の選択が役立ちます。
  3. 再生時刻の記録（Mark Playback Time）。 現在の再生時刻を選択行に記録し、次の行へ進みます。先に音声を読み込んでください。
  4. 保存（Save）。 Save は変更を保存し、エディターを開いたままにします。Save & Close は保存して閉じます。変更がない場合、Save は無効です。

設定ウィンドウ

  1. 設定カテゴリー。 カテゴリーを選びます。上の検索欄で、設定名から探すこともできます。
  2. ギャップレス再生。 次の曲を先読みします。FFmpeg と通常の速度・ピッチが必要です。次の曲から適用されます。
  3. 出力デバイス。 音声の出力先を選びます。System Default はシステムで選択した出力先を使います。

設定リファレンス

設定項目、初期値、適用範囲

プレーヤーと歌詞の設定、および初期値の一覧です。保存済み設定、セットアップのプリセット、ファイル別設定によって値が異なる場合があります。Settings を開き、カテゴリーを選んでください。項目名がわかる場合は設定検索も使えます。

全体設定とファイル別の上書き

多くの設定はアプリ全体に適用されます。Lyrics → Global は歌詞の既定値、Lyrics → Local (File) は現在のファイルの上書きです。上書きがない項目は全体設定を引き継ぎます。日本語の自動解析器は全体設定のみです。カラオケの外観と再生設定もアプリ全体に適用されます。

1 つのファイルだけ表示が違う場合は、Local (File) を先に確認してください。ファイル別設定はファイルパスに関連付けられ、LRCX 内の読み、時刻、書式とは別のものです。

翻訳

元の歌詞と翻訳行を一緒に保存する

プロバイダーを選ぶ

Settings → Plugins で Lyrics Translator を有効にします。時刻付きの歌詞がある曲を読み込み、LRC → Edit Lyrics → Translations を開きます。Provider でプロバイダーを選んでください。タブがない場合は、翻訳プロバイダーが有効で読み込まれているか確認します。

Argos はオプションのローカルパッケージとダウンロードした言語モデルを使います。クラウドサービスには接続が必要で、認証情報が必要な場合もあります。利用できるプロバイダーと言語の組み合わせはアプリ内に表示されます。

翻訳して、確認して、保存する

  1. 現在の歌詞が表示されていない場合は、パネルに読み込みます。
  2. 元の言語と翻訳先の言語を選び、翻訳する行や未翻訳行を選択します。
  3. Translate missing rows（未翻訳行）または Translate selected rows（選択行）を選びます。自動翻訳は人名、言葉遊び、文脈を誤ることがあるため、結果を読んで修正してください。
  4. Apply to lyrics editor で適用し、Save または Save & Close で保存します。

翻訳の表示行を使う場合は、元の行を残して LRCX で保存します。Lyrics タブには、 Insert Translation {\nt} もあり、同じ時刻の行内に翻訳を書き込めます。

既存の翻訳を使う

Search Lyrics には Original と Translated のプレビューがあります。翻訳付きの結果を確認し、Apply Only Translation を使うと現在の原文を保持できます。

翻訳できない場合

プロバイダー、言語の組み合わせ、必要なモデルや認証情報、接続を確認してください。Argos は依存パッケージとモデルフォルダーを確認し、クラウドサービスはプロバイダーのエラーを読んでください。歌詞の表示言語と翻訳先の言語は別の選択です。

操作チュートリアル

3 つの小さな作業を最初から最後まで

最初の曲に時刻を付ける

  1. 音声を開き、エディターで歌詞の行を順に追加します。
  2. 最初の行を選び、エディターのコントロールで再生します。
  3. その行の歌い出しで Mark Playback Time を選びます。時刻が記録され、次の行に進みます。
  4. 繰り返してから聴き直し、早すぎる／遅すぎる時刻を直します。
  5. Validate Timing で検証し、結果を確認してコピーを保存します。

最初は 3～4 行から試してください。区間ごとのカラオケ時刻は、オプションの Karaoke タブで別途設定します。

2 秒遅れる歌詞を直す

歌詞が歌い出しより常に 2 秒遅れて表示される場合は、タイムスタンプを 2 秒早めます。

  1. バックアップを保存します。
  2. Shift Timing… を開き、全行など対象の範囲を選びます。
  3. ダイアログの単位に合わせて、−2 秒または −2000 ms を入力します。正の値にすると歌詞は遅くなります。
  4. 曲の最初と最後を聴いて確認します。ずれが変わる場合は各行の時刻を直すか、正しい音源に対応した歌詞を探してください。
  5. 検証して保存します。編集中は Undo で時刻の移動を取り消せます。

Shift Timing はタイムスタンプを変更し、別の設定である歌詞オフセットは変更しません。例： [00:12.000] は、 [00:10.000] に変わります（−2 秒の移動）。

ふりがなを指定する

  1. 歌詞を開き、Source タブに切り替えます。
  2. バックアップを保存し、単語を {base|reading} の形式で囲みます。
  3. 例：[00:12.500]君の声 を [00:12.500]{君|きみ}の声 に変えます。
  4. Reload from Source でソースをエディターに反映します。
  5. Settings → Lyrics → Readings の Furigana を有効にし、確認して .lrcx で保存します。

読みを指定することで、名前や特殊な発音を修正できます。

プラグイン一覧

オプション機能のガイドを探す

プラグインは LRCPlus Community Plugins Repository からダウンロードできます。official_community_plugins で利用可能なフォルダーを確認してください。

これらはソースツリーに同梱されるプラグインです。配布ビルドの内容は異なる場合があります。Settings → Plugins で確認してください。各ガイドに設定、使い方、指定された依存パッケージを記載しています。

プラグインを追加する

  1. LRCPlus を終了します。リポジトリの Code → Download ZIP を選び、アーカイブを展開します。
  2. official_community_plugins を開き、必要なプラグインのフォルダーをそれぞれ LRCPlus installation folder\plugins\community\ にコピーします。関連ファイルも含め、フォルダー全体をコピーしてください。
  3. plugins/community/discord_rpc/plugin.py のように、各プラグインのフォルダー直下に plugin.py があることを確認します。リポジトリ全体や official_community_plugins フォルダーをそのまま community に入れないでください。plugins/core は変更・削除しないでください。
  4. LRCPlus を再起動し、Settings → Plugins を確認します。不足するパッケージは Settings → Dependencies からインストールし、案内に従って再起動します。

プラグインは Python コードを実行します。信頼できる配布元のものだけをインストールし、各プラグインの README にある追加の手順にも従ってください。
