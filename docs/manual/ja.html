LRCPlus ユーザーマニュアルより

LRCPlus マニュアルへようこそ

LRCPlus で音楽を聴き、歌詞を追いかけ、自分に合った歌詞を作るためのガイドです。

初めて使う方は、最初の曲を再生する手順から始めてください。すでに再生できる方は、歌詞の検索やタイミングの修正をお試しください。

マニュアルを読む

画面の使い方、設定リファレンス、操作チュートリアルをご覧ください。翻訳、画像カード、コンパニオンのガイドもあります。すべての記事は記事索引から探せます。

このマニュアルについて

このマニュアルは LRCPlus の現在のソース版にある操作を説明しています。ビルドや有効なプラグインによって使える機能は異なります。 Settings → Lyrics のようなメニュー表記は、アプリ内で選ぶ項目を表します。

マニュアルの閲覧と検索はすべてローカルで動作します。歌詞の取得やオンラインの読み生成サービスを使う機能には、インターネット接続が必要です。

はじめに

LRCPlus で最初の曲を聴く

LRCPlus は音楽に合わせて同期歌詞を表示します。読みの補助やカラオケのタイミングも利用できます。音声ファイルが 1 つあれば始められます。

最初の曲を再生する

  1. LRCPlus を起動します。セットアップウィザードが表示された場合は、案内に従ってください。
  2. Open → Open Audio… を選ぶか、Ctrl + O を押し、音声ファイルを選びます。
  3. Play で再生と一時停止を切り替えます。
  4. Lyrics で歌詞画面に、Library で音楽ライブラリに切り替えます。

歌詞を追加する

対応する歌詞ファイルがあれば、Open → Open Lyrics…（Ctrl + L）で開きます。ない場合は LRC → Search Lyrics でオンライン検索します。詳しくは歌詞を探すをご覧ください。

ファイル名をそろえてみましょう。 次のファイルを同じフォルダーに置きます： Song.mp3 と Song.lrc （または Song.lrcx）。両方の歌詞形式がある場合、LRCPlus は LRCX を優先します。

次にできること

  • ライブラリに音楽フォルダーを追加する。
  • ふりがなやローマ字を表示する。
  • 歌詞の行を修正する。

Settings → General → Relaunch Wizard で、セットアップウィザードを開き直せます。

音楽と再生

ライブラリ、キュー、再生コントロール

音楽ライブラリを作る

  1. Library に切り替えます。
  2. Add Music Folder をクリックし、音楽が入ったフォルダーを選びます。
  3. 音楽フォルダー内のファイルを変更したら、Rescan で反映します。

Remove Folder で、ライブラリの対象フォルダーを管理できます。

キューを使う

Open → Add to Queue…（Ctrl + Shift + O）でファイルを追加します。再生元には Library と Queue / Playlist があります。意図しない曲が再生される場合は、この選択を確認してください。

曲の中を移動する

コントロール動作
Play / Pause現在の曲を再生または一時停止します。
Stop再生を停止します。
< 5s / 5s >5 秒戻る、または 5 秒進みます。
<< / >>前の曲、または次の曲に移ります。
Volume / Mute音量を調整するか、ミュートします。

再生の設定

Settings → Playback で出力デバイス、曲／アルバム単位のシャッフル、再生後の動作（次の曲、停止、全曲リピート、1 曲リピート）を選べます。出力先に迷ったら、System Default を選んでください。

再生や画面切り替えをすばやく行うには、キーボードショートカットをご覧ください。

歌詞を探す

ファイルを読み込む、または対応する歌詞を探す

ローカルの歌詞を開く

曲を読み込み、Open → Open Lyrics… で .lrc または .lrcx を選びます。音声ファイルと同じ名前にすると自動検出しやすくなります。検索先の追加は Settings → Files で行います。

オンラインで検索する

  1. 歌詞を探したい曲を読み込みます。
  2. LRC → Search Lyrics を選びます。
  3. 検索条件を確認し、Search をクリックします。
  4. 結果を選んでプレビューを確認します。特にライブ音源やリミックスでは、アーティストと曲のバージョンが一致するか確認してください。
  5. Use Selected Lyrics をクリックして適用します。

認証情報が必要なプロバイダーもあります。LRCLIB は同期歌詞とプレーンテキスト歌詞に対応しています。オンライン検索には接続が必要です。

同期歌詞とプレーンテキスト歌詞

同期歌詞には、各行の開始時刻を示すタイムスタンプがあります。プレーンテキスト歌詞には時刻情報がありません。文字が表示されても曲に追従しない場合は、タイムスタンプの有無を確認してください。時刻は歌詞エディターで追加できます。

ローカルに保存する

LRC → Save As… で保存先を選びます。読み、カラオケの時刻、書式を保持する場合は .lrcx で保存してください。後から見つけられるよう、保存先も確認しましょう。

ふりがなと読み

歌詞を読むための補助機能

ふりがなは、日本語の歌詞に添える小さな読みです。ローマ字表示では、読みをラテン文字で表示します。LRCX に保存したルビを使うと、指定した読みを表示できます。

読みの表示方法を選ぶ

  1. Settings → Lyrics を開きます。
  2. 全体の既定値は Global、現在のファイルの設定は Local (File) を選びます。
  3. Show furigana（ふりがな）、Show romaji（ローマ字）、All romaji（すべてローマ字）のいずれかを有効にします。同時には使えません。
  4. Ruby position で読みを歌詞の上または下に配置します。

自動解析器を選ぶ

解析器必要条件
Yomi日本語の読みを生成するオンラインサービスです。インターネット接続が必要です。
MeCabオプションのローカル解析器です。fugashi と辞書を別途インストールする必要があります。

解析器は歌詞設定で選べます。依存パッケージの情報は Settings → Dependencies で確認してください。

読みを生成して修正する

LRC → Edit Lyrics を開き、Generation タブで Generate readings for all lyrics（全歌詞）または Generate For This Timestamp（この時刻のみ）を選びます。人名、特殊な表記、言葉遊びなどは読みが誤ることがあるため、保存前に確認してください。

指定した読みを LRCX に保存するには、{base|reading} の形式を使います。例：{君|きみ}。詳しくは LRCX リファレンスをご覧ください。

歌詞の編集とタイミング

歌詞を直して音楽に合わせる

曲を読み込み、LRC → Edit Lyrics を選びます。大きくタイミングを変更する前に、別名でコピーを保存してください。

歌詞の行を編集する

Lyrics タブで行を選び、本文を編集します。行の管理には + Add Line、Delete Line、Move Up、Move Down を使います。太字、斜体、取り消し線、下線、Quote（引用）の書式も使えます。

行のタイミングを設定する

  1. 時刻を設定する行を選びます。
  2. エディターの再生コントロールで、行が始まる位置を探します。 Waveform を使うと音声を波形で確認できます。
  3. 行の開始位置で Mark Playback Time を使います。選択行の時刻が更新され、次の行に進みます。波形上の仮マーカーを調整した場合は、Commit で時刻を適用します。
  4. もう一度再生して、歌詞が音楽に合っているか確認します。

Shift Timing… で時刻をまとめてずらし、Validate Timing で問題を確認できます。広い範囲に適用する前に、短い区間で試してください。

カラオケ区間のタイミングを設定する

Karaoke タブで Automatic Separation を使って区切りを用意し、内容を確認して Apply Separation で適用します。各区間の時刻には Mark Playback Time [F] を使います。必ず聴き直してください。自動分割だけでは、正確な時刻になるとは限りません。

ソースと保存

Source タブでは時刻付きの歌詞を直接確認できます。Refresh Source でエディターの内容をソースに反映し、Reload from Source でソースをエディターに読み込みます。再読み込みで編集が置き換わることがあるため、先にコピーを保存してください。

LRCX の機能を保持するには .lrcx で保存します。構文と例は LRCX リファレンスをご覧ください。

LRCX リファレンス

拡張歌詞ファイルの実用ガイド

LRCX は LRC を拡張し、カラオケ区間の時刻、ルビ、文字書式を扱えます。通常の LRC ファイルも使えます。

タイムスタンプ

[00:12.500]ここから行が始まります
[00:16.000]<00:16.000>一語 <00:16.500>ずつ <00:17.000>表示します

角括弧のタイムスタンプは行の開始時刻、山括弧のタイムスタンプはカラオケ区間の開始時刻です。分、秒、ミリ秒で指定します。

ルビ

[00:12.500]{君|きみ}の声

| の前が歌詞の本文、後が読みです。

書式と表示行

構文効果
**bold**太字
*italic*斜体
~~text~~取り消し線
<u>text</u>下線
{\n}同じ時刻の行内で、表示上の行を追加します。
> text行のタイムスタンプの直後に置くと引用になります。
[00:12.500]**1 行目**{\n}2 行目
[00:16.000]> 引用した歌詞

表示上の改行は、文字列 {\n} で表します。新しいタイムスタンプではありません。エディターでは Insert Newline {\n} を使います。

メタデータと互換性

[ar:アーティスト]
[ti:曲名]
[al:アルバム]

拡張機能を保持するには .lrcx で保存します。他の歌詞プレーヤーでは解釈できない場合があるため、互換性が必要なら通常の LRC も残してください。

完全な形式仕様は、プロジェクトの LRCX_SPEC.md を参照してください（Markdown を読めるアプリが必要な場合があります）。

カスタマイズ

読みやすく、使いやすいプレーヤーにする

外観と背景

Settings → Appearance でライト／ダークテーマ、アクセント色、テーマの保存・読み込み・書き出しを設定できます。詳細な色設定では、画面の各部の色を調整できます。

Settings → Background でアートワークの取得元や背景画像フォルダーを選び、背景の見え方を調整します。歌詞が読みにくい場合は、シンプルな背景から試してください。

歌詞のレイアウト

Settings → Lyrics でコンパクト／スクロール表示、文字方向、配置、フォント、読みを選べます。自動スクロールはタイムスタンプに追従し、連続スクロールは独立して動きます。スクロール動作で、現在の歌詞を表示範囲に保つ方法を選べます。

全体設定とファイル設定 次を使います： Global は通常の設定に使います。1 曲だけ表示が異なる場合は、 Local (File) を確認してください。

カラオケの外観

Settings → Karaoke でカラオケの外観を調整します。単語ごとの進行表示には、歌詞ファイルに区間時刻が必要です。外観設定だけでは時刻情報を追加できません。詳しくは歌詞の編集とタイミングをご覧ください。

オプション機能

コンパニオンや外部連携など、プラグインが設定を追加する場合があります。Settings → Plugins で利用可能なプラグインと設定を確認できます。

プラグイン

オプション機能を管理する

有効化と設定

  1. Settings → Plugins を開きます。
  2. 名前でプラグインを探し、説明を読みます。
  3. Enabled で有効／無効を切り替えます。コアプラグインは無効にできません。
  4. Settings ボタンがある場合は、そのボタンでプラグインを設定します。

変更によってはアプリの再起動が必要です。設定を適用しても目的のコントロールが表示されない場合は、LRCPlus を再起動してください。

依存パッケージと読み込みエラー

追加パッケージが必要な場合は、プラグインの Dependencies ボタン、または Settings → Dependencies で確認できます。読み込みに失敗すると、設定項目にエラーが表示される場合があります。その内容から不足や競合を調べてください。

プラグインを追加する

インストール方法はプラグインや配布形態によって異なります。作者の案内に従ってください。ソース版は plugins ディレクトリから検出します。すべての配布版で同じ場所に書き込めるとは限りません。

開発者向けの情報は、別のプラグイン API ドキュメントにあります（Markdown を読めるアプリが必要な場合があります）。

トラブルシューティング

目に見える症状から確認する

音が出ない

  1. 再生中であることと、ミュートになっていないことを確認します。
  2. プレーヤーの音量と Windows の音量ミキサーを確認します。
  3. Settings → Playback で、出力デバイスに System Default を試します。
  4. 正常に再生できる別の音声ファイルを試し、その曲だけの問題か確認します。

歌詞が表示されない

Lyrics に切り替え、Ctrl + L で歌詞ファイルを開くか、LRC → Search Lyrics を使います。ファイル名と Settings → Files の検索先を確認してください。LRC と LRCX が両方ある場合は、優先される LRCX を先に確認します。

歌詞のタイミングが合わない

歌詞が音源と一致するか確認してください。ライブ版、リミックス、イントロの違いで時刻が変わります。タイムスタンプの有無も確認します。全体のずれは Shift Timing… で修正できます。途中でずれが変わる場合は各行を直してください。

読みが表示されない、または正しくない

Settings → Lyrics の読みのモードと、Local (File) の設定を確認します。Yomi は接続、MeCab はローカルのパッケージと辞書が必要です。自動生成結果を確認し、特定の読みが必要な語には LRCX のルビを指定してください。

プラグインが使えない

Settings → Plugins で有効状態と読み込みエラーを確認します。パッケージが不足していれば Dependencies も確認してください。設定変更後、必要に応じて再起動します。

問題を報告する

Settings → About の LRCPlus バージョン、Windows のバージョン、再現手順、期待する動作、実際の動作を記載してください。他の曲でも起きるか、プラグインが関係するかも役立ちます。時刻や描画の問題には、小さな歌詞の例を添えてください。

画面の使い方

実際のアプリ画面を番号付きで案内します

青い番号を選ぶと、対応する説明に移動します。画像はサンプル歌詞と独立した設定を使った実際のソース版です。プラグインやテーマによってコントロールが変わる場合があります。画像内のアプリ表示は英語です。

プレーヤーと歌詞画面

  1. ライブラリ画面。 音楽コレクションに戻ります。Lyrics でこの歌詞画面に戻れます。
  2. LRC メニュー。 LRC をクリックすると現在の歌詞を編集できます。矢印から Search Lyrics、Save As などを開けます。
  3. 歌詞表示。 同期歌詞を表示します。表示モード、フォント、配置、読みは Settings → Lyrics で調整します。
  4. 行の一覧。 時刻付きの行一覧を展開／折りたたみます。展開した一覧の行をクリックすると、その時刻に移動します。
  5. シークバー。 再生位置を移動します。音声がない場合は、再生時間と移動範囲は 0 のままです。
  6. 再生と一時停止。 一時停止／再開します。隣のボタンで停止、5 秒移動、曲の切り替えができます。
  7. 音量。 音量を調整します。Mute では、保存した音量値を変えずに音を消せます。

ライブラリ画面

  1. ライブラリ検索。 ファイルを変更せずにライブラリを絞り込みます。
  2. 音楽ライブラリ。 フォルダーを追加すると曲が表示されます。ダブルクリックで再生し、列見出しの右クリックで表示列を管理できます。
  3. ファイルを開く。 Open Audio で音声を読み込み、Add to Queue でキューに追加し、Open Lyrics で歌詞を付けます。
  4. 設定。 設定画面を開きます。カテゴリー一覧と設定検索から項目を探せます。
  5. 再生コントロール。 どちらの画面でも再生操作ができます。Play from で Library または Queue / Playlist を選んでください。

歌詞エディター

  1. エディターのタブ。 Lyrics、Generation、Source、Share、Advanced を切り替えます。プラグインがタブを追加する場合もあります。
  2. 時刻付きの歌詞行。 編集する行を選びます。長い文書では Search、Previous、Next、並び順の選択が役立ちます。
  3. 再生時刻の記録（Mark Playback Time）。 現在の再生時刻を選択行に記録し、次の行へ進みます。先に音声を読み込んでください。
  4. 保存（Save）。 Save は変更を保存し、エディターを開いたままにします。Save & Close は保存して閉じます。変更がない場合、Save は無効です。

設定ウィンドウ

  1. 設定カテゴリー。 カテゴリーを選びます。上の検索欄で、設定名から探すこともできます。
  2. ギャップレス再生。 次の曲を先読みします。FFmpeg と通常の速度・ピッチが必要です。次の曲から適用されます。
  3. 出力デバイス。 音声の出力先を選びます。System Default はシステムで選択した出力先を使います。

設定リファレンス

設定項目、初期値、適用範囲

プレーヤーと歌詞の設定、および初期値の一覧です。保存済み設定、セットアップのプリセット、ファイル別設定によって値が異なる場合があります。Settings を開き、カテゴリーを選んでください。項目名がわかる場合は設定検索も使えます。

全体設定とファイル別の上書き

多くの設定はアプリ全体に適用されます。Lyrics → Global は歌詞の既定値、Lyrics → Local (File) は現在のファイルの上書きです。上書きがない項目は全体設定を引き継ぎます。日本語の自動解析器は全体設定のみです。カラオケの外観と再生設定もアプリ全体に適用されます。

1 つのファイルだけ表示が違う場合は、Local (File) を先に確認してください。ファイル別設定はファイルパスに関連付けられ、LRCX 内の読み、時刻、書式とは別のものです。

翻訳

元の歌詞と翻訳行を一緒に保存する

プロバイダーを選ぶ

Settings → Plugins で Lyrics Translator を有効にします。時刻付きの歌詞がある曲を読み込み、LRC → Edit Lyrics → Translations を開きます。Provider でプロバイダーを選んでください。タブがない場合は、翻訳プロバイダーが有効で読み込まれているか確認します。

Argos はオプションのローカルパッケージとダウンロードした言語モデルを使います。クラウドサービスには接続が必要で、認証情報が必要な場合もあります。利用できるプロバイダーと言語の組み合わせはアプリ内に表示されます。

翻訳して、確認して、保存する

  1. 現在の歌詞が表示されていない場合は、パネルに読み込みます。
  2. 元の言語と翻訳先の言語を選び、翻訳する行や未翻訳行を選択します。
  3. Translate missing rows（未翻訳行）または Translate selected rows（選択行）を選びます。自動翻訳は人名、言葉遊び、文脈を誤ることがあるため、結果を読んで修正してください。
  4. Apply to lyrics editor で適用し、Save または Save & Close で保存します。

翻訳の表示行を使う場合は、元の行を残して LRCX で保存します。Lyrics タブには、 Insert Translation {\nt} もあり、同じ時刻の行内に翻訳を書き込めます。

既存の翻訳を使う

Search Lyrics には Original と Translated のプレビューがあります。翻訳付きの結果を確認し、Apply Only Translation を使うと現在の原文を保持できます。

翻訳できない場合

プロバイダー、言語の組み合わせ、必要なモデルや認証情報、接続を確認してください。Argos は依存パッケージとモデルフォルダーを確認し、クラウドサービスはプロバイダーのエラーを読んでください。歌詞の表示言語と翻訳先の言語は別の選択です。

共有と画像カード

テキストを書き出す、または歌詞の画像を作る

テキストをコピー／書き出す

  1. LRC → Edit Lyrics → Share → Text を開きます。
  2. 本文だけなら Plain text、行の時刻も含めるなら With line timestamps を選びます。
  3. Copy でクリップボードにコピーし、Export… でファイルに書き出します。

共有されるのは歌詞テキストで、音声は含まれません。編集可能な LRCX 全体を保持するには、エディターの保存操作を使ってください。

画像カードを作る

  1. エディターで Share → Image card を開きます。
  2. 行のチェックで抜粋を選び、プレビューを確認します。
  3. レイアウトのテンプレートを選び、文字、アートワーク、背景を調整します。
  4. カードのコントロールで画像を書き出します。

テンプレートには Classic、Spotlight、Record sleeve、Polaroid、Editorial、Cinema があります。アートワークは任意です。Cinema では、アルバム画像をぼかした背景にできます。

読みと書式

Preserve LRCX formatting を有効にすると、行内の強調、引用、表示上の改行、小さな翻訳行を保持します。ふりがなは別の設定で、指定済みまたは生成済みの読みを使います。画像カードから読みの生成は開始されないため、足りない読みは先にエディターで生成してください。

横書きと縦書きに対応しています。曲の詳細には曲名、アーティストやクレジット、アルバムを入れられます。書き出す前に、文字の切れや表示できない文字がないか確認してください。タイムスタンプと再生中のカラオケ強調はカードには印刷されません。

櫻林 純美（さくらばやし あやみ）、通称 Ayami は、LRCPlus のセットアップウィザードを擬人化した架空のキャラクターです。プレーヤーの紹介や初期設定を案内し、設定後はオプションの音楽コンパニオンとして再び登場します。

キャラクター設定ではコンピューター科学を学ぶ高校生とされ、正確な年齢は非公開です。姓の「櫻林」は「櫻」と「林」を組み合わせたもので、桜への愛着を表しています。

性格

社交的で想像力が豊か、芝居がかった表現を好み、照れやすい性格です。架空のクリップボードや台本を持ち出して説明を大げさにすることもありますが、人を手伝う役目には真剣です。技術的な説明にネットスラングや皮肉を交え、ときには少し乱暴な言葉も使います。

音楽やコンピューターの話をするのが好きで、自分の意見を持ち、ふと素直な一面を見せることもあります。開発者とのやり取りには、冗談の言い争いや第四の壁を破る演出があります。説明を飛ばす、異なる意見を持つ、会話を終えるといった利用者の選択も尊重します。

興味と好み

音楽、桜、タイポグラフィ、詩、アニメ、ゲーム、絵、チョコレートなどを好みます。辛い食べ物、おやつ、日本料理も好きです。一方、キュウリ、餃子、キムチは苦手とされています。

趣味は作詞・作曲、動画編集、3D モデリング、OS のカスタマイズ、Python と C++ のプログラミングなど。創作と技術の両方を楽しみます。

「正直、私は Sakura が好き。でも、これはあなたのプレーヤーだから、私の一票は飾りみたいなものね。」（台詞の日本語訳）

LRCPlus で Ayami に会う

初回セットアップでは、あらかじめ書かれた台詞で設定を案内します。もう一度会うには Settings → General → Relaunch Wizard を選びます。設定画面から開き直すとコンパニオン画面に入り、Run setup again で元のセットアップに戻れます。

コンパニオン画面では、自分で設定したプロバイダーを使うオプションのチャットを利用できます。音楽を聴くためにチャットを設定する必要はありません。接続設定、保存した会話、記憶の操作については、コンパニオンガイドをご覧ください。

台詞と記憶

セットアップの台詞には、LRCPlus 独自の Ren'Py 風スクリプトエンジンを使っています。あらかじめ書かれた分岐とイベントの記録により、選択肢、テーマ、ウィンドウの移動など、対応する操作に反応します。これらの台詞と、設定したモデルが返答を生成するオプションの AI チャットは別の仕組みです。

スクリプトの変数や台詞の状態は、保存したチャットや記憶の情報とも別です。チャットが使うのは渡された会話と有効な記憶で、曲、歌詞、プレーヤーの設定は送信されません。返答からアプリの操作を実行することもできません。保存する情報やメッセージに含める内容は、記憶の設定で選べます。

キャラクターの背景

Ayami は、初期設定の体験に一貫した個性を持たせるために作られました。開発開始日は 2026 年 11 月 6 日で、誕生日の 11 月 6 日はその日を記念しています。ユーモア、会話の分岐、豊かな反応もキャラクター表現の一部です。

背景や好みは、プロジェクトのキャラクター設定に記載されています。スクリプトによる案内とオプションのチャットの違いは、オンボーディングのドキュメントを参照してください（英語。Markdown を読めるアプリが必要な場合があります）。

Ayami とのチャット、会話、保存した記憶

コンパニオンを開く

Ayami のオプションチャットは、コンパニオンを有効にしたセットアップウィザードに表示されます。Settings → General → Relaunch Wizard で開き直せます。チャットは音楽再生とは独立しており、曲を聴くために設定する必要はありません。

チャットを設定する

AI settings… を開き、対応するプロバイダーの API ベース URL、モデル ID、キーを入力します。ローカルサーバーではキーが不要な場合があります。内蔵のキーのヘルプに設定方法があります。保存してメッセージを入力し、Send を選びます。Regenerate は別の返答を要求し、Stop は実行中の要求を中止します。

送信すると、会話、キャラクターの指示、有効な記憶が選択したプロバイダーに渡されます。曲、歌詞、設定は添付されません。記憶するキーとカスタムヘッダーは、利用できる場合は Windows アカウントの暗号化で保護され、それ以外は現在のセッションだけに保持されます。

保存した会話

保存済み会話の選択欄でチャットを切り替えます。New conversation で新規作成し、Rename と Delete で管理します。長い返答は Previous と Next でページを移動できます。

保存する記憶を管理する

Memories… を開き、事実を 1 行ずつ編集します。今後のメッセージに含めるかも選べます。1 件 200 文字まで、最大 20 件を保存できます。

自動記憶モードは Off（オフ）、Suggest for approval（承認用に提案、既定）、Automatically save ordinary preferences（通常の好みを自動保存）から選びます。抽出に追加の要求を使う場合があります。Review で候補を承認／却下し、Sources で出所を確認できます。Check now で確認を要求し、Stop check で中止します。

操作チュートリアル

3 つの小さな作業を最初から最後まで

最初の曲に時刻を付ける

  1. 音声を開き、エディターで歌詞の行を順に追加します。
  2. 最初の行を選び、エディターのコントロールで再生します。
  3. その行の歌い出しで Mark Playback Time を選びます。時刻が記録され、次の行に進みます。
  4. 繰り返してから聴き直し、早すぎる／遅すぎる時刻を直します。
  5. Validate Timing で検証し、結果を確認してコピーを保存します。

最初は 3～4 行から試してください。区間ごとのカラオケ時刻は、オプションの Karaoke タブで別途設定します。

2 秒遅れる歌詞を直す

歌詞が歌い出しより常に 2 秒遅れて表示される場合は、タイムスタンプを 2 秒早めます。

  1. バックアップを保存します。
  2. Shift Timing… を開き、全行など対象の範囲を選びます。
  3. ダイアログの単位に合わせて、−2 秒または −2000 ms を入力します。正の値にすると歌詞は遅くなります。
  4. 曲の最初と最後を聴いて確認します。ずれが変わる場合は各行の時刻を直すか、正しい音源に対応した歌詞を探してください。
  5. 検証して保存します。編集中は Undo で時刻の移動を取り消せます。

Shift Timing はタイムスタンプを変更し、別の設定である歌詞オフセットは変更しません。例： [00:12.000] は、 [00:10.000] に変わります（−2 秒の移動）。

ふりがなを指定する

  1. 歌詞を開き、Source タブに切り替えます。
  2. バックアップを保存し、単語を {base|reading} の形式で囲みます。
  3. 例：[00:12.500]君の声 を [00:12.500]{君|きみ}の声 に変えます。
  4. Reload from Source でソースをエディターに反映します。
  5. Show furigana を有効にして表示を確認し、.lrcx で保存します。

読みを指定することで、名前や特殊な発音を修正できます。

Anki Flashcards

同梱プラグインガイド

歌詞の語を選び、Anki に取り込める TSV の単語カードを書き出します。

セットアップ

歌詞の語を選び、カードの内容を確認して、Anki 用の TSV を書き出します。

使い方

歌詞を読み込んでからプラグインのカード操作を使います。Anki に取り込む前に出力項目を確認してください。この機能はファイルを書き出し、デッキを自動変更するものではありません。

必要条件

このプラグインのマニフェストに追加パッケージの指定はありません。

読み込みエラーは Settings → Plugins、パッケージの状態は Settings → Dependencies で確認します。Python パッケージのインストールだけでは、外部サービスの設定は完了しません。

Cantonese Readings

同梱プラグインガイド

プラグイン API v2 の広東語の読みです。PyCantonese で Jyutping と Yale を生成します。

セットアップ

Settings → Dependencies に表示される PyCantonese をインストールします。

使い方

Jyutping と Yale の読みプロバイダーを登録します。広東語の内容に合ったモードを選んでください。長い歌詞は解析に時間がかかる場合があります。確認が表示されたら、今すぐ生成するか、生成せずに読み込むか選びます。

必要条件

  • pycantonese>=3.4,<4

読み込みエラーは Settings → Plugins、パッケージの状態は Settings → Dependencies で確認します。Python パッケージのインストールだけでは、外部サービスの設定は完了しません。

Discord Rich Presence

同梱プラグインガイド

曲の情報、歌詞、アルバム画像で Discord のアクティビティをカスタマイズします。

セットアップ

Discord を起動し、Settings → Plugins → Discord Rich Presence → Settings を設定します。

使い方

Discord のアクティビティに出す曲の情報、歌詞、画像を選びます。表示されない場合は、Discord、プラグインの有効状態、依存パッケージを確認してください。

必要条件

  • pypresence>=4.6,<5
  • requests>=2,<3
  • mutagen>=1,<2

読み込みエラーは Settings → Plugins、パッケージの状態は Settings → Dependencies で確認します。Python パッケージのインストールだけでは、外部サービスの設定は完了しません。

Floating Lyrics

同梱プラグインガイド

ふりがな付きの歌詞を、切り離せる最前面ウィンドウに表示します。

セットアップ

歌詞付きの曲を読み込み、Plugins → Floating Lyrics を選びます。

使い方

プラグインの Settings で最前面ウィンドウを設定できます。同じメニュー操作でもう一度切り替えると非表示になります。メインプレーヤーは引き続き使えます。

必要条件

このプラグインのマニフェストに追加パッケージの指定はありません。

読み込みエラーは Settings → Plugins、パッケージの状態は Settings → Dependencies で確認します。Python パッケージのインストールだけでは、外部サービスの設定は完了しません。

Korean Romanization

同梱プラグインガイド

Koroman を使い、発音を考慮した韓国語の改訂ローマ字表記を生成します。

セットアップ

このプラグインに指定されている Koroman をインストールします。

使い方

韓国語の改訂ローマ字表記プロバイダーを登録します。韓国語の読み生成を選び、発音の出力を確認してから保存してください。

必要条件

  • koroman>=1,<2

読み込みエラーは Settings → Plugins、パッケージの状態は Settings → Dependencies で確認します。Python パッケージのインストールだけでは、外部サービスの設定は完了しません。

Lyrics Translator

同梱プラグインガイド

オプションのオフライン Argos、または Azure、Google Cloud、DeepL、MyMemory で歌詞の行を翻訳します。

セットアップ

プラグインを有効にし、エディターの Translations タブでプロバイダーを選びます。

使い方

Argos はオプションのローカルパッケージと言語モデルが必要です。クラウドサービスには接続と認証情報が必要です。結果を確認して文書に適用してから保存してください。

必要条件

  • argostranslate==1.11.0（オプション）

読み込みエラーは Settings → Plugins、パッケージの状態は Settings → Dependencies で確認します。Python パッケージのインストールだけでは、外部サービスの設定は完了しません。

yt-dlp Audio Import

同梱プラグインガイド

YouTube 検索や URL から音声と字幕を取り込みます。同期歌詞や MusicBrainz のアルバム画像も利用できます。

セットアップ

Plugins → Search and import audio… を開き、結果を選ぶか対応する URL を入力します。

使い方

ダウンロード前に取り込み設定と保存先を確認してください。音声と字幕に加え、同期歌詞やアルバム画像を取り込めます。失敗した場合は設定と依存パッケージのエラーを確認します。

必要条件

  • yt-dlp[default]>=2026.3.3
  • mutagen>=1,<2

読み込みエラーは Settings → Plugins、パッケージの状態は Settings → Dependencies で確認します。Python パッケージのインストールだけでは、外部サービスの設定は完了しません。

Karaoke Screen

同梱プラグインガイド

全画面の歌詞表示と、オプションの MIDI 音程ガイドです。

セットアップ

Karaoke Screen を読み込んだ状態で、プレーヤーの Karaoke Screen ボタンを押すと全画面の歌詞を開けます。プラグイン設定の名前は Karaoke Game です。

使い方

全画面の歌詞と、任意の MIDI 音程ガイドを提供します。音程ガイドには対応する MIDI データが必要です。歌詞の時刻と MIDI の音符は別の入力です。

必要条件

このプラグインのマニフェストに追加パッケージの指定はありません。

読み込みエラーは Settings → Plugins、パッケージの状態は Settings → Dependencies で確認します。Python パッケージのインストールだけでは、外部サービスの設定は完了しません。
