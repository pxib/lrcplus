설명서는 온라인과 앱에 포함된 사본으로 제공됩니다. 포함된 사본은 인터넷 없이 읽고 검색할 수 있습니다. 온라인 가사 검색과 온라인 읽기 제공자에는 인터넷 연결이 필요합니다.

시작하기

LRCPlus에서 첫 곡 재생하기

LRCPlus는 음악과 동기화 가사를 함께 재생하며 읽기 보조와 노래방 타이밍도 지원합니다. 오디오 파일 하나만으로 시작할 수 있습니다.

첫 곡 재생하기

  1. LRCPlus를 실행합니다. 초기 설정 마법사가 나타나면 안내를 따릅니다.
  2. Open → Open Audio… 또는 Ctrl + O로 오디오 파일을 선택합니다.
  3. Play로 재생하거나 일시 정지합니다.
  4. 가사 (Lyrics)로 가사 화면을, Library로 음악 목록을 엽니다.

가사 추가하기

가사 파일이 있다면 Open → Open Lyrics… (Ctrl + L)로 엽니다. 온라인에서 찾으려면 LRC → Search Lyrics를 선택합니다. 자세한 절차는 가사 찾기를 참고하세요.

파일 이름을 맞춰 보세요. Song.mp3와 Song.lrc 또는 Song.lrcx를 같은 폴더에 둡니다. 두 가사 형식이 모두 있으면 LRCX가 우선합니다.

다음 단계

  • 라이브러리에 음악 폴더 추가하기
  • 후리가나 또는 로마자 표기 켜기
  • 가사 한 줄 수정하기

Settings → General → Relaunch Wizard에서 설정 마법사를 다시 열 수 있습니다.

음악과 재생

라이브러리, 대기열과 재생 컨트롤

음악 라이브러리 만들기

  1. Library로 전환합니다.
  2. Add Music Folder를 누르고 음악 폴더를 선택합니다.
  3. 폴더 안의 파일을 변경했다면 Rescan을 사용합니다.

Remove Folder로 라이브러리에 포함할 폴더를 관리합니다.

대기열 사용하기

Open → Add to Queue… (Ctrl + Shift + O)로 파일을 추가합니다. 재생 소스 선택기에서 Library 또는 Queue / Playlist를 고릅니다. 예상과 다른 목록의 곡이 재생되면 이 선택기를 확인하세요.

오디오 파일을 대기열에 놓으면 끝에 추가합니다. 라이브러리에서 선택한 곡을 오른쪽 클릭해 Play now, Play next, Add to queue를 사용합니다. Play now는 현재 대기열 항목 뒤에 삽입하고 바로 재생하며 Play next는 다음 재생을 위해 삽입합니다. Add to saved playlist는 새 재생목록을 만들거나 기존 목록에 덧붙입니다. 곡 메뉴에서 파일 위치 열기, 경로나 파일명 복사, 속성 확인도 할 수 있습니다.

취침 타이머

카운트다운, 곡 종료 동작과 취소는 취침 타이머를 참고하세요.

재생 환경 설정

Settings → Playback에서 출력 장치, 곡 또는 앨범 단위 무작위 재생, 재생 후 동작(다음 곡, 중지, 전체 반복, 한 곡 반복)을 선택합니다. 출력 장치가 확실하지 않다면 System Default로 시작하세요.

빠르게 조작하려면 키보드 단축키를 참고하세요.

곡 검색과 즐겨찾기

곡명, 아티스트, 앨범으로 검색하거나 로컬 가사 검색에서 색인된 가사 내용을 찾습니다. 일반 곡 정보 검색에 결과가 없으면 네 글자 이상인 단어의 글자 하나 누락·추가·오타·순서 바뀜도 찾아 Close matches로 표시합니다. 짧은 단어, 숫자와 가사 검색은 입력 그대로 찾습니다.

현재 곡이나 라이브러리의 하트를 눌러 즐겨찾기에 추가합니다. 라이브러리와 대기열의 오른쪽 클릭 메뉴로 선택한 여러 곡을 추가하거나 해제할 수 있습니다. Favorites 필터는 두 검색 방식과 함께 사용할 수 있습니다. 즐겨찾기는 파일 경로로 저장되어 재검색 후에도 남지만 파일을 옮기면 자동으로 따라가지 않습니다.

라이브러리에 가져오고 제거하기

오디오 파일이나 폴더를 메인 플레이어에 놓으면 백그라운드에서 가져옵니다. 놓을 위치의 미리보기는 Library 추가인지 대기열 끝에 추가인지 보여줍니다. 라이브러리 가져오기는 Library 화면을 열고 가져온 곡을 선택합니다. 곡을 보여주기 위해 검색 및 Favorites 필터가 해제될 수 있습니다.

곡이나 앨범을 오른쪽 클릭해 Remove from library를 선택하면 디스크 파일, 대기열, 즐겨찾기와 저장된 재생목록을 유지하며 라이브러리 항목만 제거합니다. 다시 검색하거나 재시작해도 제외 상태가 유지됩니다. 제외된 오디오 파일을 라이브러리에 다시 놓으면 복원됩니다.

가중치 셔플

Settings → Playback → Shuffle에서 Weighted tracks를 선택하고 하단 Shuffle을 켭니다. Favor favorite songs는 즐겨찾기의 가중치를 두 배로 합니다. Favor songs not played recently는 최근 들은 곡의 가중치를 평소의 20%로 낮춘 뒤 14일에 걸쳐 원래대로 돌립니다. 대상 곡 모두가 선택될 가능성을 유지합니다.

최근 재생 시점은 통계 기록이 켜져 있을 때만 사용합니다. 기록이 꺼져 있어도 즐겨찾기 가중치는 작동합니다. 직접 지정한 대기열은 우선합니다.

하단에서 곡 반복, 횟수 반복, A-B 구간, 속도와 음정도 조절합니다. 곡별 마커는 앱 종료까지 유지되며 취침 타이머가 우선합니다.

반복과 연습

곡이나 구간을 반복하고 노래하기 편한 속도와 음정으로 조절하기

곡 전체 반복하기

플레이어 하단 Shuffle 옆의 Repeat를 엽니다. Repeat off는 현재 라이브러리나 대기열을 한 번 재생하고, Repeat all은 목록을 반복하며, Repeat current track은 한 곡을 계속 반복합니다.

  1. 연습할 곡을 불러옵니다.
  2. Play current track N times...에서 총횟수를 2~999로 지정합니다.
  3. 총 세 번이면 3을 입력합니다. 곡 중간에 설정해도 현재 재생이 첫 번째에 포함됩니다.
  4. Repeat: 1/3 같은 진행 표시를 확인합니다. 마지막 재생 뒤에는 정상적으로 다음 곡으로 넘어갑니다.

Stop, 곡 변경 또는 다른 반복 모드 선택으로 횟수 반복이 취소됩니다. 횟수는 현재 세션에서만 유지됩니다.

어려운 구간 반복하기

  1. 구절 시작으로 이동해 A-B → Set A at current position을 선택합니다.
  2. 끝까지 재생하거나 이동한 다음 Set B and loop를 선택합니다. B는 A보다 최소 0.1초 뒤여야 합니다.
  3. 재생 위치가 A로 돌아옵니다. 일시 정지 상태라면 Play를 누르세요. 마커를 설정해도 자동으로 재생을 시작하지 않습니다.
  4. Clear A-B loop로 일반 재생으로 돌아갑니다. A를 다시 설정해도 B가 지워집니다.

탐색 막대에 양쪽 깃발과 범위가 표시됩니다. 각 곡의 마커는 LRCPlus를 종료할 때까지 유지되며 다른 곡에서 돌아오면 복원됩니다. 같은 파일의 대기열 항목은 마커를 공유합니다. Stop은 마커를 유지하고 Clear는 현재 곡의 범위만 지웁니다. 오디오 길이가 바뀌면 유효하지 않은 경계가 해제될 수 있습니다.

속도와 음정 조절하기

하단의 Pitch에서 재생 속도와 음정을 조절합니다. 빠른 구절은 속도를 낮추고 노래할 조는 음정으로 바꿀 수 있습니다. 음정 아래에는 한 옥타브 낮게 부를 때의 차이도 표시됩니다. 예를 들어 +4반음은 한 옥타브 낮게 부르면 원곡보다 −8반음입니다.

속도와 음정은 곡 사이에 공유되는 저장된 재생 설정이며 Lyrics → Local (File)의 표시 설정과 별개입니다. 원래 소리로 돌아가려면 속도 100%, 음정 0반음으로 설정합니다.

연습 기능을 함께 사용할 때

곡 전체의 횟수 반복을 마치려면 먼저 A-B 범위를 해제하세요. 범위가 표시된 동안 크로스페이드와 다음 곡 미리 읽기가 중단됩니다. 취침 타이머가 구간 반복과 곡 반복보다 우선합니다. 끊김 없는 재생과 크로스페이드에는 FFmpeg, 정상 속도, 음정 변경 없음이 필요합니다. 재생 설정을 참고하세요.

취침 타이머

정해진 시간 뒤나 곡이 끝날 때 일시 정지하기

타이머 시작하기

  1. 플레이어 하단의 Sleep을 누릅니다.
  2. 15, 30, 45, 60, 90분 또는 Custom…으로 1~720분을 선택합니다.
  3. When time is up에서 Pause immediately(즉시 일시 정지) 또는 Finish the current song(현재 곡 끝까지 재생)을 선택합니다.
  4. Start timer를 누릅니다. 창을 닫아도 타이머는 계속 실행됩니다.

시간을 지정하지 않고 불러온 곡이 끝날 때 멈추려면 At the end of this song을 선택합니다.

확인, 연장, 취소하기

Sleep 버튼에 남은 시간이 표시됩니다. 다시 열면 상태와 예상 종료 시각을 볼 수 있습니다. Add 5 minutes는 진행 중인 카운트다운을 5분 연장합니다. 새 시간을 정하고 Replace timer를 누르면 교체됩니다. Cancel timer는 재생을 멈추지 않고 타이머를 취소합니다.

일시 정지 중에도 카운트다운은 계속됩니다. Stop은 타이머를 취소합니다. 마지막 시간과 종료 동작은 기억하지만 실행 중인 타이머는 앱 종료 시 지워집니다.

곡이 끝날 때의 동작 이해하기

Finish the current song은 카운트다운이 끝날 때 재생 중인 곡을 마친 뒤 반복이나 다음 곡으로 넘어가기 전에 일시 정지합니다. 기다리는 동안 Sleep: song이 표시됩니다. A-B 반복보다 우선하므로 곡을 끝까지 재생할 수 있습니다.

끝을 기다리는 동안 다음 곡으로 건너뛰면 타이머가 종료되고 선택한 곡은 멈춘 상태로 남습니다. 다시 들으려면 Play를 누르세요. 예를 들어 30분 뒤 현재 곡을 마치는 설정은 실제로 30분을 넘길 수 있습니다. 정확한 시점에 멈추려면 Pause immediately를 선택하세요.

기록을 켠 뒤의 청취부터 저장합니다. Recent나 라이브러리에서 이전 재생 기록을 복원하지는 않습니다.

대시보드 살펴보기

Today, Last 7 days, Last 30 days, All time을 선택합니다. 청취 시간, 재생 횟수, 서로 다른 곡 수, 일별 활동과 곡·아티스트·앨범 상위 100개를 확인할 수 있습니다. All time 그래프는 최근 365일을 보여주지만 합계에는 기록된 전체 기간이 포함됩니다.

청취로 계산되는 항목

실제로 재생한 시간을 계산하므로 빠르게 재생해도 20초 동안 들으면 약 20초가 더해집니다. 일시 정지, 탐색으로 건너뛴 구간, 버퍼링, 시스템 절전, 플레이어 음소거와 플레이어 음량 0은 청취 시간에 포함되지 않습니다.

한 번의 재생에서 30초 또는 곡 길이의 절반 중 짧은 시간만큼 들으면 재생 횟수를 한 번 더합니다. 일시 정지 후 재개와 탐색은 같은 재생으로 취급하며 반복이나 처음부터 다시 시작은 새로운 재생입니다. 짧게 들으면 시간만 늘고 횟수는 늘지 않을 수 있습니다.

기록 관리하기

기록은 이 기기에 저장됩니다. 기록을 꺼도 기존 합계는 유지됩니다. Clear statistics…는 확인 후 기록을 삭제하며 음악, 재생목록, Recent 항목은 유지합니다. 파일 경로로 곡을 구분하므로 파일을 옮기면 별도 항목이 됩니다.

가중치 셔플은 기록이 켜져 있을 때만 최근 재생 시점을 사용합니다. 설정 내보내기에는 기록 사용 여부가 포함되지만 청취 기록 자체는 포함되지 않습니다.

설정 가져오기·내보내기와 초기화

설치를 옮길 때 환경설정을 전송하고 기본값 검토하기

환경설정 파일 내보내기

  1. Settings → Advanced를 엽니다.
  2. Export settings…로 JSON 파일을 저장합니다.

저장하지 않은 변경을 포함해 현재 표시된 설정을 내보냅니다. 모양, 저장된 테마, 재생 및 전역 가사 환경설정, 가사 검색 폴더, 업데이트 설정, 플러그인 설정이 포함됩니다.

내보내기 범위: 음악 라이브러리 데이터, 저장된 재생목록, 기록, 곡별 가사 설정, 읽기 사전은 별도로 저장됩니다. 이 파일은 환경설정을 옮깁니다. 개인 읽기 사전에는 사전 관리자의 내보내기를 사용하세요.

가져오고 검토하기

  1. Import settings…에서 내보낸 JSON 파일을 선택합니다. 유효하지 않은 파일은 오류를 표시합니다.
  2. 적용 전에 탭을 검토합니다. 다른 컴퓨터로 옮길 때 폴더 경로와 오디오 출력을 확인하세요.
  3. OK로 적용하거나 Cancel로 가져온 초안을 버립니다.
  4. 가져온 플러그인 설정을 적용한 뒤 LRCPlus를 다시 시작합니다.

환경설정 가져오기는 별도로 저장된 라이브러리, 재생목록, 기록, 곡별 설정과 사전을 유지합니다.

기본 설정 검토하기

Advanced에서 Restore factory defaults…를 선택해 탭을 검토한 뒤 OK로 적용하거나 Cancel로 버립니다. 저장된 테마, 폴더, 플러그인 설정, 라이브러리, 재생목록, 기록, 곡별 설정과 읽기 사전은 유지됩니다.

현재 기본값은 어두운 Nordic Frost, 강조색 #88c0d0, 배경 흐림 없음, 재생목록 복원 켜짐입니다. 자동 업데이트 확인과 통계 기록은 꺼져 있습니다. 개인 사전을 시작 항목으로 바꾸려면 사전 관리자에서 Manage → Restore factory dictionaries…를 사용하고 두 창 모두에서 OK를 누르세요.

가사 찾기

파일을 열거나 곡에 맞는 버전 검색하기

로컬 가사 열기

곡을 불러온 다음 Open → Open Lyrics…에서 .lrc 또는 .lrcx 파일을 선택합니다. 오디오와 가사 파일의 이름을 맞추면 자동 검색에 도움이 됩니다. 추가 검색 폴더는 Settings → Files에서 관리합니다.

온라인 검색

  1. 가사를 찾을 곡을 불러옵니다.
  2. LRC → Search Lyrics를 선택합니다.
  3. 검색 정보를 확인하고 검색를 누릅니다.
  4. 결과의 미리보기를 읽고 아티스트와 곡 버전을 확인합니다. 라이브 녹음과 리믹스는 특히 주의하세요.
  5. Use Selected Lyrics로 적용합니다.

일부 제공자는 인증 정보가 필요합니다. LRCLIB는 동기화 가사와 일반 텍스트 가사를 지원합니다. 온라인 검색에는 인터넷 연결이 필요합니다.

동기화 가사와 일반 텍스트

동기화 가사에는 각 줄의 시작 시간을 알려 주는 타임스탬프가 있습니다. 일반 텍스트 가사에는 시간이 없습니다. 글은 보이지만 곡을 따라 움직이지 않으면 타임스탬프가 있는지 확인하세요. 가사 편집기에서 시간을 추가할 수 있습니다.

로컬 사본 저장하기

LRC → Save As…로 원하는 위치에 저장합니다. 읽기, 노래방 타이밍 또는 서식이 필요하면 .lrcx를 사용하세요. 나중에 찾을 수 있도록 저장 위치를 확인합니다.

후리가나와 읽기

가사를 위한 읽기 보조

후리가나는 일본어 가사 옆에 표시되는 작은 읽기 표기입니다. 로마자는 읽기를 라틴 문자로 표시합니다. LRCX 루비에는 직접 작성한 읽기도 저장할 수 있습니다.

읽기 표시 선택하기

  1. Settings → Lyrics에서 Global 또는 Local (File)을 고르고 Readings를 엽니다.
  2. Lyric layers의 Lyrics, Romaji, Translation, Furigana를 각각 켜거나 끕니다. 최소 하나는 켜 두어야 합니다.
  3. 끌어서 옮기거나 Move up / Move down을 누릅니다. 레이어를 선택한 뒤 Alt + ↑ / ↓도 사용할 수 있습니다.

Romaji는 Lyrics와 함께 있으면 작게, 단독이면 기본 크기로 표시됩니다. Translation은 가사 파일에 저장된 번역 행을 표시하며 번역을 생성하지 않습니다. 순서와 표시 여부는 Compact, Scrolling, Floating Lyrics에 적용되며 일시 정지 중에도 갱신됩니다. 로마자만 보려면 Romaji를 켜고 나머지를 끄세요.

자동 파서 선택하기

파서요구 사항
Yomi온라인 일본어 읽기 제공자입니다. 인터넷 연결이 필요합니다.
MeCab선택 사항인 로컬 파서입니다. fugashi와 별도로 설치한 사전이 필요합니다.

파서 선택기는 가사 설정에 있습니다. 의존성 정보는 Settings → Dependencies에서 확인합니다.

읽기 생성과 수정

LRC → Edit Lyrics → Generation에서 Generate readings for all lyrics 또는 Generate For This Timestamp를 선택합니다. 이름, 특이한 표기와 말장난은 자동 결과가 틀릴 수 있으므로 저장 전에 확인하세요.

직접 작성한 읽기는 {base|reading} 형식으로 보존합니다. 예: {君|きみ}. LRCX 참조도 살펴보세요.

개인 읽기 수정 저장하기

  1. Settings → Lyrics → Global → Readings → Manage reading dictionaries…를 엽니다.
  2. Manage → New dictionary… 다음 Add entry를 선택합니다. 예를 들어 Reading에 あす, Word에 明日, Reading type에 Japanese furigana를 입력합니다.
  3. 일반 항목은 Whole word를 유지하세요. Inside words는 큰 단어의 일부까지 의도적으로 일치시킬 때 사용합니다.
  4. 사전 관리자와 Settings에서 차례로 OK를 눌러 저장합니다. Cancel은 해당 창의 초안을 버립니다.

체크한 사전만 사용합니다. 가장 긴 유효 일치가 우선하며 같은 유형의 같은 단어는 첫 번째 활성 사전을 사용합니다. Manage로 우선순위를 바꿀 수 있습니다. 곡에 직접 저장한 루비가 사전보다 우선합니다. 번역이나 노래방 타이밍은 바뀌지 않습니다.

일본어 후리가나, 중국어 병음, 한국어 로마자, 광둥어 Jyutping과 Yale을 지원합니다. 일본어는 가나로 입력하면 Romaji가 변환합니다. Manage는 JSON/TSV 및 Google 일본어 입력기 내보내기 파일을 가져오고 선택 사전을 JSON/TSV로 내보냅니다. 가져오기는 별도 사전을 만듭니다. 새 설치에는 Japanese song readings의 私 → わたし, 君 → きみ, 時 → とき가 포함됩니다.

편집과 타이밍

가사를 수정하고 음악에 맞추기

곡을 불러오고 LRC → Edit Lyrics를 선택합니다. 타이밍을 크게 바꾸기 전에는 별도 사본을 저장하세요.

편집 내용 미리 보기와 파형 탐색

Lyrics에서 줄을 선택하고 입력란 아래의 Live preview에서 서식, 읽기 표기, 재생 강조를 확인하세요. 긴 구절을 편집할 때는 Expand text를 사용하세요.

Lyrics 또는 Karaoke에서 Waveform을 켜세요. 이동 및 확대 버튼으로 구간을 살피고, Fit line으로 선택한 줄에 맞추거나 All audio로 곡 전체를 볼 수 있습니다. 가사 타이밍을 바꾸지 않고 재생 위치를 옮기려면 Ctrl을 누른 채 파형을 왼쪽 클릭하세요. 편집기의 어느 탭에서든 F1을 눌러 Shortcuts를 열고 검색할 수 있습니다.

곡을 불러오지 않은 상태에서 가사 편집기를 열고 Create New LRCX 또는 Open LRCX를 선택하세요. 저장하지 않은 초안의 복구 사본이 있다면 시작 화면에서 Recover Draft로 열고 편집을 마친 후 저장하세요.

가사 줄 편집하기

가사 (Lyrics) 탭에서 줄을 선택하고 텍스트를 수정합니다. + Add Line, Delete Line, Move Up, Move Down으로 문서를 관리합니다. 굵게, 기울임, 취소선, 밑줄과 Quote 서식을 사용할 수 있습니다.

줄 타이밍 지정하기

  1. 타이밍을 지정할 줄을 선택합니다.
  2. 편집기의 재생 컨트롤로 줄의 시작 위치를 찾습니다. Waveform으로 오디오를 살펴볼 수 있습니다.
  3. 줄이 시작하는 순간 Mark Playback Time을 누릅니다. 선택한 줄의 시간이 갱신되고 다음 줄로 이동합니다. 임시 파형 마커를 조정했다면 Commit으로 적용합니다.
  4. 다시 재생하여 가사가 음악을 따라가는지 확인합니다.

일정한 시간 차이는 Shift Timing…으로 조정하고 Validate Timing으로 타이밍 문제를 확인합니다. 전체를 이동하기 전에 짧은 구간에서 시험하세요.

노래방 구간 타이밍 지정하기

노래방 (Karaoke) 탭에서 Automatic Separation으로 구간 경계를 준비하고 확인한 뒤 Apply Separation을 누릅니다. 구간을 따라가며 Mark Playback Time [F]를 사용합니다. 자동 분리가 정확한 타이밍을 보장하지는 않으므로 다시 들어보세요.

원문과 저장

Source 탭에서 타이밍을 포함한 가사 원문을 확인합니다. Refresh Source와 Reload from Source로 구조화된 편집기와 원문 사이를 이동합니다. 다시 불러오면 편집 내용이 바뀔 수 있으므로 사본을 먼저 저장하세요.

LRCX 기능을 유지하려면 .lrcx로 저장합니다. 문법과 예시는 LRCX 참조를 참고하세요.

화면에서 읽기 수정하기

Lyrics 탭에서 단어 위의 읽기나 작은 더하기 표시를 눌러 수정합니다. Enter는 적용하고 Escape는 취소합니다. 인접 조각을 합치려면 한 단어를 클릭하고 옆 조각을 Shift 클릭한 뒤 오른쪽 클릭 메뉴의 Combine reading을 선택합니다. 한 단어를 선택해 Split reading...을 누르면 본문 경계와 두 읽기를 검토할 수 있습니다. 공백이나 줄바꿈을 넘어 합칠 수는 없습니다.

가사 본문, 타이밍, 서식과 번역 행을 유지하며 Undo/Redo를 지원합니다. 직접 쓴 읽기와 단어 묶음을 보존하려면 LRCX로 저장합니다.

여러 행 편집과 타이밍 검토

Shift/Ctrl로 여러 행을 선택하고 Selected Lines…에서 시간 이동, 서식, 행 이동 또는 삭제를 선택합니다. 미리보기가 제공되면 확인하세요. Split at Cursor…는 현재 행을 나누며 Merge with Next…나 Merge Selected…는 공백, 줄바꿈 또는 구분자 없이 합칩니다.

본문 수정은 바뀌지 않은 조각의 타이밍을 유지합니다. 시간 지정 조각 안에서 나누면 새 경계를 추정하므로 강조된 조각을 다시 들어 보세요. Undo/Redo는 문서 편집과 선택을 복원합니다.

LRCX 참조

확장 가사 파일 사용 안내

LRCX는 LRC에 노래방 구간 타이밍, 루비 읽기와 텍스트 서식을 더한 형식입니다. 일반 LRC 파일도 사용할 수 있습니다.

타임스탬프

[00:12.500]The line begins here
[00:16.000]<00:16.000>One <00:16.500>word <00:17.000>at a time

대괄호의 시간은 줄의 시작, 꺾쇠괄호의 시간은 노래방 구간의 시작을 나타냅니다. 시간은 분, 초, 밀리초로 표시합니다.

루비 읽기

[00:12.500]{君|きみ}の声

| 앞은 기본 가사, 뒤는 읽기입니다.

서식과 표시 행

문법효과
**bold**굵게
*italic*기울임
~~text~~취소선
<u>text</u>밑줄
{\n}같은 타이밍의 줄 안에서 표시 행을 나눕니다.
> text줄 타임스탬프 바로 뒤에 놓으면 인용문이 됩니다.
[00:12.500]**First row**{\n}Second row
[00:16.000]> A quoted lyric

줄바꿈 표시는 실제 문자열 {\n}이며 새 타임스탬프가 아닙니다. 편집기에서는 Insert Newline {\n}을 사용합니다.

메타데이터와 호환성

[ar:Artist]
[ti:Song title]
[al:Album]

확장 기능을 보존하려면 .lrcx 확장자를 사용합니다. 다른 플레이어는 확장을 지원하지 않을 수 있습니다. 다른 플레이어와의 호환성이 필요하면 일반 LRC 사본도 보관하세요.

전체 형식 명세는 프로젝트의 LRCX_SPEC.md에 있습니다. Markdown 뷰어가 필요할 수 있습니다.

사용자 설정

보기 편하고 쓰기 편한 플레이어 만들기

테마와 배경

Settings → Appearance → Theme에서 Light, Dark 또는 Use Qt Theme를 선택합니다. Qt 모드는 기본 위젯 스타일과 시스템 색상을 사용합니다. Light나 Dark로 돌아가면 사용자 색상을 다시 사용할 수 있습니다. Appearance에서 테마 저장, 가져오기와 내보내기도 할 수 있습니다.

Settings → Background에서 앨범 아트 소스나 사용자 배경 폴더를 선택하고 배경 효과를 조정합니다. 가사를 읽기 어렵다면 단순한 배경부터 사용하세요.

가사 배치

Settings → Lyrics에서 간결한 표시 또는 스크롤 표시, 쓰기 방향, 정렬, 글꼴과 읽기를 선택합니다. 자동 스크롤은 타임스탬프를 따르고 연속 스크롤은 독립적으로 움직입니다. 스크롤 동작은 현재 가사를 화면에 유지하는 방식을 정합니다.

전체 설정인가요, 파일별 설정인가요? 평소 설정은 Global을 사용합니다. 한 곡만 다르게 동작하면 Local (File)을 확인하세요.

노래방 표시

Settings → Karaoke에서 노래방 표시를 조정합니다. 단어별 진행에는 가사 파일의 구간 타이밍이 필요합니다. 모양 설정만으로 누락된 타이밍을 추가할 수는 없습니다. 편집과 타이밍을 참고하세요.

선택 기능

동반자와 외부 연동 등 추가 설정은 플러그인에서 제공할 수 있습니다. Settings → Plugins에서 설치된 플러그인과 설정을 확인합니다.

플러그인

선택 기능 관리하기

활성화와 설정

  1. Settings → Plugins를 엽니다.
  2. 이름으로 플러그인을 찾고 설명을 읽습니다.
  3. Enabled 체크 상자로 활성 상태를 바꿉니다. 핵심 플러그인은 끌 수 없습니다.
  4. Settings 버튼이 있으면 눌러 해당 플러그인을 설정합니다.

일부 변경에는 앱 재시작이 필요합니다. 설정을 적용해도 예상한 컨트롤이 보이지 않으면 LRCPlus를 다시 시작하세요.

의존성과 로드 오류

플러그인에 추가 패키지가 필요할 수 있습니다. 플러그인의 Dependencies 버튼이나 Settings → Dependencies에서 정보를 확인합니다. 로드하지 못한 플러그인의 설정 항목에 오류가 표시되면 누락되거나 충돌하는 요구 사항을 확인하세요.

플러그인 추가하기

LRCPlus Community Plugins Repository에서 플러그인을 다운로드할 수 있습니다. official_community_plugins에서 제공되는 플러그인 폴더를 확인하세요.

  1. LRCPlus를 종료합니다. 저장소에서 Code → Download ZIP을 선택하고 압축을 풉니다.
  2. official_community_plugins를 열고 원하는 개별 플러그인 폴더를 LRCPlus installation folder\plugins\community\에 복사합니다. 관련 파일을 포함한 폴더 전체를 복사하세요.
  3. plugins/community/discord_rpc/plugin.py처럼 각 플러그인 폴더 바로 안에 plugin.py가 있어야 합니다. 저장소 전체 폴더나 official_community_plugins 폴더를 통째로 community에 넣지 마세요. plugins/core는 그대로 두세요.
  4. LRCPlus를 다시 시작하고 Settings → Plugins에서 확인합니다. 필요한 패키지는 Settings → Dependencies에서 설치하고 안내에 따라 다시 시작합니다.

플러그인은 Python 코드를 실행합니다. 신뢰하는 출처의 플러그인만 설치하고 각 플러그인의 README에 있는 추가 안내를 따르세요.

개발 안내는 플러그인 API 문서에 있습니다. Markdown 뷰어가 필요할 수 있습니다.

문제 해결

눈에 보이는 증상부터 확인하기

재생해도 소리가 나지 않음

  1. 재생 중인지, 음소거 상태가 아닌지 확인합니다.
  2. 플레이어 음량과 Windows 볼륨 믹서를 확인합니다.
  3. Settings → Playback에서 출력 장치를 System Default로 바꿔 봅니다.
  4. 정상적인 다른 오디오 파일을 열어 특정 곡에만 생기는 문제인지 확인합니다.

가사가 표시되지 않음

가사 (Lyrics)로 전환합니다. Ctrl + L로 가사를 직접 열거나 LRC → Search Lyrics를 사용합니다. 파일 이름과 Settings → Files의 검색 폴더를 확인합니다. LRC와 LRCX가 모두 있으면 우선하는 LRCX 파일부터 확인하세요.

가사가 잘못된 시간에 표시됨

라이브, 리믹스나 도입부가 다른 녹음은 타이밍이 다를 수 있습니다. 가사가 녹음 버전과 맞고 타임스탬프가 있는지 확인합니다. 일정한 차이는 Shift Timing…으로 조정하고 곡의 위치에 따라 달라지면 개별 줄을 수정합니다.

읽기가 없거나 잘못됨

Settings → Lyrics의 읽기 모드와 Local (File) 설정을 확인합니다. Yomi에는 연결이, MeCab에는 로컬 패키지와 사전이 필요합니다. 자동 결과를 검토하고 특정 읽기가 필요하면 LRCX 루비를 직접 작성하세요.

플러그인을 사용할 수 없음

Settings → Plugins에서 활성 상태와 로드 오류를 확인합니다. 패키지가 누락되었다면 Dependencies를 살펴보세요. 설정 변경 후 필요하면 다시 시작합니다.

문제 보고하기

Settings → About의 LRCPlus 버전, Windows 버전, 재현 단계, 예상 동작과 실제 결과를 적습니다. 다른 곡에서도 발생하는지, 선택 플러그인을 사용하는지도 알려주세요. 타이밍이나 표시 문제를 설명하는 데 도움이 되면 짧은 가사 예시를 포함합니다.

화면 안내

실제 앱 화면을 번호로 살펴보기

번호가 있는 화면에서 설명서에 나오는 컨트롤을 찾으세요. 파란 번호를 선택하면 설명으로 이동합니다. 스크린샷은 예시 가사와 별도 설정으로 실행한 실제 소스 버전의 화면입니다. 플러그인과 테마에 따라 컨트롤이 추가되거나 달라질 수 있습니다.

플레이어와 가사 화면

  1. 라이브러리 화면. 음악 목록으로 돌아갑니다. Lyrics를 누르면 가사 화면으로 전환합니다.
  2. LRC 메뉴. LRC를 눌러 현재 가사를 편집합니다. 화살표를 누르면 Search Lyrics, Save As 등의 가사 작업을 엽니다.
  3. 가사 표시. 동기화 가사를 표시합니다. Settings → Lyrics에서 표시 모드, 글꼴, 정렬과 읽기를 조정합니다.
  4. 줄 목록. 시간이 있는 줄 목록을 펼치거나 접습니다. 펼친 목록에서 줄을 누르면 해당 시간으로 이동합니다.
  5. 탐색 막대. 다른 재생 위치로 이동합니다. 오디오가 없으면 길이와 탐색 범위는 0입니다.
  6. 재생 또는 일시 정지. 재생을 멈추거나 계속합니다. 옆 버튼으로 중지, 5초 이동과 곡 전환을 합니다.
  7. 음량. 음량을 조정합니다. Mute는 저장된 음량을 유지하면서 소리를 끕니다.

라이브러리 화면

  1. 라이브러리 검색. 파일을 바꾸지 않고 라이브러리 목록을 필터링합니다.
  2. 음악 라이브러리. 폴더를 추가하면 곡이 표시됩니다. 두 번 눌러 재생하고 열 제목을 마우스 오른쪽 버튼으로 눌러 표시할 열을 관리합니다.
  3. 파일 열기. Open Audio는 오디오를 불러오고 Add to Queue는 대기열에 추가하며 Open Lyrics는 가사를 연결합니다.
  4. 설정. 환경 설정을 엽니다. 분류 목록과 설정 검색으로 옵션을 찾습니다.
  5. 재생 컨트롤. 두 화면 모두에서 재생 컨트롤을 사용할 수 있습니다. Play from에서 Library 또는 Queue / Playlist를 선택하세요.

가사 편집기

  1. 편집기 작업 화면. Lyrics, Generation, Source, Share, Advanced 사이를 전환합니다. 선택 플러그인이 화면을 추가할 수 있습니다.
  2. 시간이 있는 가사 줄. 편집할 줄을 선택합니다. Search, Previous, Next와 정렬 선택기로 긴 문서를 탐색합니다.
  3. 재생 시간 기록. 선택한 줄에 현재 재생 시간을 기록하고 다음 줄로 이동합니다. 먼저 오디오를 불러오세요.
  4. 저장. Save는 편집기를 유지하며 저장합니다. Save & Close는 저장 후 닫습니다. 변경이 없으면 Save가 비활성화됩니다.

설정 창

  1. 설정 분류. 분류를 선택합니다. 위의 검색창에서 이름으로 설정을 찾을 수 있습니다.
  2. 끊김 없는 재생. 다음 곡을 미리 버퍼링합니다. FFmpeg와 기본 속도·음높이가 필요하며 다음 곡부터 적용됩니다.
  3. 출력 장치. 출력 장치를 선택합니다. System Default는 시스템이 선택한 출력을 따릅니다.

전체 설정과 파일별 재정의

대부분의 분류는 앱 전체에 적용됩니다. Lyrics → Global 은 가사 표시 기본값을 제공하고 Lyrics → Local (File) 은 현재 파일의 선택 옵션을 재정의합니다. 별도 설정이 없는 파일은 전체 값을 사용합니다. 자동 일본어 파서는 전체 설정 전용 입니다. 노래방 표시와 재생 설정도 앱 전체에 적용됩니다.

한 파일만 다르게 보이면 Local (File)부터 확인하세요. 파일별 재정의는 파일 경로에 연결되며 LRCX 문서 안의 읽기, 타임스탬프와 서식과는 별개입니다.

번역, 검토와 저장

  1. 현재 가사 문서가 보이지 않으면 패널로 불러옵니다.
  2. 원본 언어와 대상 언어를 고르고 번역할 행이나 비어 있는 행을 선택합니다.
  3. Translate missing rows 또는 Translate selected rows를 선택합니다. 이름, 말장난과 문맥을 놓칠 수 있으므로 결과를 읽고 수정하세요.
  4. Apply to lyrics editor 후 Save 또는 Save & Close로 저장합니다.

번역 표시 행을 사용하면 원문을 유지하고 LRCX로 저장하세요. Lyrics 탭의 Insert Translation {\nt}로 같은 타이밍의 줄 안에 번역을 작성할 수도 있습니다.

제공자, 언어 조합, 필요한 모델이나 인증 정보, 연결을 확인합니다. Argos는 선택 의존성과 모델 폴더를 확인하고 클라우드 서비스는 제공자 오류를 읽으세요. 가사 표시 언어와 번역 대상 언어는 별도로 선택합니다.

성격

Ayami는 외향적이고 상상력이 풍부하며 연극적이고 쉽게 당황합니다. 가상의 클립보드나 큐카드를 꺼내는 공연 같은 설명을 하더라도 도움을 주는 일에는 진지합니다. 기술 설명, 가벼운 인터넷 말투, 무심한 빈정거림과 가끔 나오는 거친 표현이 섞인 말투를 사용합니다.

음악과 컴퓨터를 설명하는 것을 즐기고 자기 의견이 있으며 뜻밖에 진지해지기도 합니다. 개발자와 장난스러운 논쟁이나 제4의 벽을 넘는 농담을 나눕니다. 사용자가 설명을 건너뛰거나 반대하거나 떠나는 선택을 존중합니다.

음악, 벚꽃, 타이포그래피, 시, 애니메이션, 게임, 그림과 초콜릿에 관심이 있습니다. 매운 음식, 간식과 일본 요리를 좋아하며 오이, 만두와 김치는 싫어한다고 합니다.

작곡, 영상 편집, 3D 모델링, 운영체제 만지기와 Python·C++ 프로그래밍처럼 창작과 기술을 아우르는 취미가 있습니다.

LRCPlus에서 Ayami 만나기

처음 실행할 때 Ayami는 미리 작성된 대사로 설정을 안내합니다. 다시 만나려면 Settings → General → Relaunch Wizard를 선택하세요. 설정에서 다시 열면 재방문 사용자용 동반자 창이 나타나고 Run setup again 으로 원래 마법사로 돌아갑니다.

동반자 창은 설정한 제공자를 통한 선택 채팅 기능을 제공합니다. 채팅을 설정하지 않아도 음악을 들을 수 있습니다. 제공자 설정, 저장된 대화와 기억 관리는 동반자 안내를 참고하세요.

대화와 기억

설정 대화는 Ren'Py에서 영감을 받은 LRCPlus 스크립트 엔진을 사용합니다. 작성된 분기와 이벤트 추적으로 선택, 테마와 창 이동 등 지원되는 이벤트에 반응합니다. 이 스크립트 대화는 설정한 모델이 응답하는 선택 AI 채팅과 별개입니다.

스크립트 변수와 대화 상태도 저장된 채팅 및 기억 정보와 별개입니다. 채팅에는 제공한 대화와 켜 둔 기억만 사용하며 곡, 가사나 플레이어 설정은 전달하지 않습니다. 채팅 응답으로 앱을 조작할 수 없습니다. 기억 관리 에서 저장하고 메시지에 포함할 내용을 선택하세요.

동반자 열기

Ayami의 선택 채팅 기능은 동반자 기능이 켜진 설정 마법사에 있습니다. Settings → General → Relaunch Wizard로 다시 엽니다. 채팅 설정 없이도 음악을 재생할 수 있습니다.

채팅 설정하기

AI settings…에서 호환 제공자의 API 기본 URL, 모델 ID와 키를 입력합니다. 로컬 서버에는 키가 필요하지 않을 수 있습니다. 내장 키 도움말에서 제공자 설정을 확인하세요. 저장 후 메시지를 입력하고 Send를 누릅니다. Regenerate는 다른 응답을 요청하고 Stop은 진행 중인 요청을 취소합니다.

메시지를 보내면 대화, 캐릭터 지침과 활성화한 기억이 선택한 제공자에게 전송됩니다. 곡, 가사와 플레이어 설정은 첨부되지 않습니다. 저장한 키와 사용자 헤더는 가능하면 Windows 계정 암호화를 사용하며, 그렇지 않으면 현재 세션에만 유지됩니다.

저장된 대화

저장된 대화 선택기로 채팅을 바꿉니다. New conversation으로 새 대화를 만들고 Rename과 Delete로 관리합니다. 긴 응답은 Previous와 Next로 페이지를 이동합니다.

저장된 기억 관리하기

Memories…에서 한 줄에 사실 하나씩 편집하고 앞으로 보낼 메시지에 포함할지 선택합니다. 각 200자 이내로 최대 20개를 저장할 수 있습니다.

자동 기억 모드는 꺼짐, 기본값인 Suggest for approval, Automatically save ordinary preferences가 있습니다. 추출 과정에서 추가 제공자 요청이 발생할 수 있습니다. Review로 제안을 수락하거나 버리고, Sources로 출처를 확인하며, Check now로 검사를 요청하거나 Stop check로 취소합니다.

실습 안내

처음부터 끝까지 따라 하는 세 가지 작업

첫 곡의 타이밍 지정하기

  1. 오디오를 열고 편집기에 가사 줄을 순서대로 추가합니다.
  2. 첫 줄을 선택하고 편집기의 컨트롤로 재생합니다.
  3. 노래의 해당 줄이 시작할 때 Mark Playback Time을 누릅니다. 시간이 기록되고 다음 줄로 이동합니다.
  4. 반복한 뒤 다시 듣고 빠르거나 늦은 시간을 수정합니다.
  5. Validate Timing으로 확인하고 사본을 저장합니다.

처음에는 3~4줄로 시작하세요. 구간별 노래방 타이밍은 선택 사항인 Karaoke 탭에서 별도로 지정합니다.

2초 늦게 나오는 가사 고치기

가사가 항상 노래보다 2초 늦게 표시되면 타임스탬프를 2초 앞당깁니다.

  1. 백업 사본을 저장합니다.
  2. Shift Timing…에서 모든 줄 등 적용 범위를 정합니다.
  3. 대화상자의 단위에 맞춰 −2초 또는 −2000ms를 입력합니다. 양수는 가사를 늦춥니다.
  4. 곡의 시작과 끝에서 확인합니다. 차이가 달라지면 개별 시간을 수정하거나 녹음 버전에 맞는 가사를 찾으세요.
  5. 검사하고 저장합니다. 편집 중에는 실행 취소로 이동을 되돌릴 수 있습니다.

Shift Timing은 타임스탬프를 바꾸며 별도 가사 오프셋은 바꾸지 않습니다. −2초 이동하면 [00:12.000]은 [00:10.000]이 됩니다.

사용자 후리가나 추가하기

  1. 가사 문서를 열고 Source로 전환합니다.
  2. 백업 후 단어를 {base|reading}으로 감쌉니다.
  3. 예를 들어 [00:12.500]君の声를 [00:12.500]{君|きみ}の声로 바꿉니다.
  4. Reload from Source로 편집기에 적용합니다.
  5. Settings → Lyrics → Readings에서 Furigana를 켜고 검토한 뒤 .lrcx로 저장합니다.

직접 작성한 읽기로 이름이나 특이한 발음을 바로잡을 수 있습니다.

플러그인 목록

선택 기능의 안내 찾기

LRCPlus Community Plugins Repository에서 플러그인을 다운로드할 수 있습니다. official_community_plugins에서 제공되는 플러그인 폴더를 확인하세요.

소스에 포함된 플러그인입니다. 패키지 빌드에는 다른 구성이 포함될 수 있습니다. Settings → Plugins에서 사용 가능 여부를 확인하세요. 각 안내에는 설정, 사용법과 선언된 의존성이 있습니다.

플러그인 추가하기

  1. LRCPlus를 종료합니다. 저장소에서 Code → Download ZIP을 선택하고 압축을 풉니다.
  2. official_community_plugins를 열고 원하는 개별 플러그인 폴더를 LRCPlus installation folder\plugins\community\에 복사합니다. 관련 파일을 포함한 폴더 전체를 복사하세요.
  3. plugins/community/discord_rpc/plugin.py처럼 각 플러그인 폴더 바로 안에 plugin.py가 있어야 합니다. 저장소 전체 폴더나 official_community_plugins 폴더를 통째로 community에 넣지 마세요. plugins/core는 그대로 두세요.
  4. LRCPlus를 다시 시작하고 Settings → Plugins에서 확인합니다. 필요한 패키지는 Settings → Dependencies에서 설치하고 안내에 따라 다시 시작합니다.

플러그인은 Python 코드를 실행합니다. 신뢰하는 출처의 플러그인만 설치하고 각 플러그인의 README에 있는 추가 안내를 따르세요.
