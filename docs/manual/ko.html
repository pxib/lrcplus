이 설명서에 대하여

이 설명서는 현재 LRCPlus 소스 버전의 기능을 설명합니다. 빌드와 활성 플러그인에 따라 사용할 수 있는 기능이 다릅니다. Settings → Lyrics와 같은 경로는 앱에서 선택할 메뉴를 나타냅니다. 실제 화면에서 찾기 쉽도록 메뉴와 버튼 이름은 영어로 유지합니다.

설명서는 온라인과 앱에 포함된 사본으로 제공됩니다. 포함된 사본은 인터넷 없이 읽고 검색할 수 있습니다. 온라인 가사 검색과 온라인 읽기 제공자에는 인터넷 연결이 필요합니다.

시작하기

LRCPlus에서 첫 곡 재생하기

LRCPlus는 음악과 동기화 가사를 함께 재생하며 읽기 보조와 노래방 타이밍도 지원합니다. 오디오 파일 하나만으로 시작할 수 있습니다.

첫 곡 재생하기

  1. LRCPlus를 실행합니다. 초기 설정 마법사가 나타나면 안내를 따릅니다.
  2. Open → Open Audio… 또는 Ctrl + O로 오디오 파일을 선택합니다.
  3. Play로 재생하거나 일시 정지합니다.
  4. 가사 (Lyrics)로 가사 화면을, Library로 음악 목록을 엽니다.

가사 추가하기

가사 파일이 있다면 Open → Open Lyrics… (Ctrl + L)로 엽니다. 온라인에서 찾으려면 LRC → Search Lyrics를 선택합니다. 자세한 절차는 가사 찾기를 참고하세요.

파일 이름을 맞춰 보세요. Song.mp3와 Song.lrc 또는 Song.lrcx를 같은 폴더에 둡니다. 두 가사 형식이 모두 있으면 LRCX가 우선합니다.

다음 단계

  • 라이브러리에 음악 폴더 추가하기
  • 후리가나 또는 로마자 표기 켜기
  • 가사 한 줄 수정하기

Settings → General → Relaunch Wizard에서 설정 마법사를 다시 열 수 있습니다.

음악과 재생

라이브러리, 대기열과 재생 컨트롤

음악 라이브러리 만들기

  1. Library로 전환합니다.
  2. Add Music Folder를 누르고 음악 폴더를 선택합니다.
  3. 폴더 안의 파일을 변경했다면 Rescan을 사용합니다.

Remove Folder로 라이브러리에 포함할 폴더를 관리합니다.

대기열 사용하기

Open → Add to Queue… (Ctrl + Shift + O)로 파일을 추가합니다. 재생 소스 선택기에서 Library 또는 Queue / Playlist를 고릅니다. 예상과 다른 목록의 곡이 재생되면 이 선택기를 확인하세요.

곡 안에서 이동하기

컨트롤동작
Play / Pause현재 곡을 재생하거나 일시 정지합니다.
Stop재생을 중지합니다.
< 5s / 5s >5초 뒤로 또는 앞으로 이동합니다.

Volume / Mute음량을 조절하거나 음소거합니다.

재생 환경 설정

Settings → Playback에서 출력 장치, 곡 또는 앨범 단위 무작위 재생, 재생 후 동작(다음 곡, 중지, 전체 반복, 한 곡 반복)을 선택합니다. 출력 장치가 확실하지 않다면 System Default로 시작하세요.

빠르게 조작하려면 키보드 단축키를 참고하세요.

가사 찾기

파일을 열거나 곡에 맞는 버전 검색하기

로컬 가사 열기

곡을 불러온 다음 Open → Open Lyrics…에서 .lrc 또는 .lrcx 파일을 선택합니다. 오디오와 가사 파일의 이름을 맞추면 자동 검색에 도움이 됩니다. 추가 검색 폴더는 Settings → Files에서 관리합니다.

온라인 검색

  1. 가사를 찾을 곡을 불러옵니다.
  2. LRC → Search Lyrics를 선택합니다.
  3. 검색 정보를 확인하고 검색를 누릅니다.
  4. 결과의 미리보기를 읽고 아티스트와 곡 버전을 확인합니다. 라이브 녹음과 리믹스는 특히 주의하세요.
  5. Use Selected Lyrics로 적용합니다.

일부 제공자는 인증 정보가 필요합니다. LRCLIB는 동기화 가사와 일반 텍스트 가사를 지원합니다. 온라인 검색에는 인터넷 연결이 필요합니다.

동기화 가사와 일반 텍스트

동기화 가사에는 각 줄의 시작 시간을 알려 주는 타임스탬프가 있습니다. 일반 텍스트 가사에는 시간이 없습니다. 글은 보이지만 곡을 따라 움직이지 않으면 타임스탬프가 있는지 확인하세요. 가사 편집기에서 시간을 추가할 수 있습니다.

로컬 사본 저장하기

LRC → Save As…로 원하는 위치에 저장합니다. 읽기, 노래방 타이밍 또는 서식이 필요하면 .lrcx를 사용하세요. 나중에 찾을 수 있도록 저장 위치를 확인합니다.

후리가나와 읽기

가사를 위한 읽기 보조

후리가나는 일본어 가사 옆에 표시되는 작은 읽기 표기입니다. 로마자는 읽기를 라틴 문자로 표시합니다. LRCX 루비에는 직접 작성한 읽기도 저장할 수 있습니다.

읽기 표시 선택하기

  1. Settings → Lyrics를 엽니다.
  2. 전체 기본값은 Global, 현재 파일은 Local (File)을 선택합니다.
  3. Show furigana, Show romaji, All romaji 중 하나를 켭니다. 이 모드들은 동시에 사용할 수 없습니다.
  4. Ruby position으로 가사 위나 아래에 후리가나를 배치합니다.

자동 파서 선택하기

파서요구 사항
Yomi온라인 일본어 읽기 제공자입니다. 인터넷 연결이 필요합니다.
MeCab선택 사항인 로컬 파서입니다. fugashi와 별도로 설치한 사전이 필요합니다.

파서 선택기는 가사 설정에 있습니다. 의존성 정보는 Settings → Dependencies에서 확인합니다.

읽기 생성과 수정

LRC → Edit Lyrics → Generation에서 Generate readings for all lyrics 또는 Generate For This Timestamp를 선택합니다. 이름, 특이한 표기와 말장난은 자동 결과가 틀릴 수 있으므로 저장 전에 확인하세요.

직접 작성한 읽기는 {base|reading} 형식으로 보존합니다. 예: {君|きみ}. LRCX 참조도 살펴보세요.

편집과 타이밍

가사를 수정하고 음악에 맞추기

곡을 불러오고 LRC → Edit Lyrics를 선택합니다. 타이밍을 크게 바꾸기 전에는 별도 사본을 저장하세요.

가사 줄 편집하기

가사 (Lyrics) 탭에서 줄을 선택하고 텍스트를 수정합니다. + Add Line, Delete Line, Move Up, Move Down으로 문서를 관리합니다. 굵게, 기울임, 취소선, 밑줄과 Quote 서식을 사용할 수 있습니다.

줄 타이밍 지정하기

  1. 타이밍을 지정할 줄을 선택합니다.
  2. 편집기의 재생 컨트롤로 줄의 시작 위치를 찾습니다. Waveform으로 오디오를 살펴볼 수 있습니다.
  3. 줄이 시작하는 순간 Mark Playback Time을 누릅니다. 선택한 줄의 시간이 갱신되고 다음 줄로 이동합니다. 임시 파형 마커를 조정했다면 Commit으로 적용합니다.
  4. 다시 재생하여 가사가 음악을 따라가는지 확인합니다.

일정한 시간 차이는 Shift Timing…으로 조정하고 Validate Timing으로 타이밍 문제를 확인합니다. 전체를 이동하기 전에 짧은 구간에서 시험하세요.

노래방 구간 타이밍 지정하기

노래방 (Karaoke) 탭에서 Automatic Separation으로 구간 경계를 준비하고 확인한 뒤 Apply Separation을 누릅니다. 구간을 따라가며 Mark Playback Time [F]를 사용합니다. 자동 분리가 정확한 타이밍을 보장하지는 않으므로 다시 들어보세요.

원문과 저장

Source 탭에서 타이밍을 포함한 가사 원문을 확인합니다. Refresh Source와 Reload from Source로 구조화된 편집기와 원문 사이를 이동합니다. 다시 불러오면 편집 내용이 바뀔 수 있으므로 사본을 먼저 저장하세요.

LRCX 기능을 유지하려면 .lrcx로 저장합니다. 문법과 예시는 LRCX 참조를 참고하세요.

LRCX 참조

확장 가사 파일 사용 안내

LRCX는 LRC에 노래방 구간 타이밍, 루비 읽기와 텍스트 서식을 더한 형식입니다. 일반 LRC 파일도 사용할 수 있습니다.

타임스탬프

[00:12.500]The line begins here
[00:16.000]<00:16.000>One <00:16.500>word <00:17.000>at a time

대괄호의 시간은 줄의 시작, 꺾쇠괄호의 시간은 노래방 구간의 시작을 나타냅니다. 시간은 분, 초, 밀리초로 표시합니다.

루비 읽기

[00:12.500]{君|きみ}の声

| 앞은 기본 가사, 뒤는 읽기입니다.

서식과 표시 행

문법효과
**bold**굵게
*italic*기울임
~~text~~취소선
<u>text</u>밑줄
{\n}같은 타이밍의 줄 안에서 표시 행을 나눕니다.
> text줄 타임스탬프 바로 뒤에 놓으면 인용문이 됩니다.
[00:12.500]**First row**{\n}Second row
[00:16.000]> A quoted lyric

줄바꿈 표시는 실제 문자열 {\n}이며 새 타임스탬프가 아닙니다. 편집기에서는 Insert Newline {\n}을 사용합니다.

메타데이터와 호환성

[ar:Artist]
[ti:Song title]
[al:Album]

확장 기능을 보존하려면 .lrcx 확장자를 사용합니다. 다른 플레이어는 확장을 지원하지 않을 수 있습니다. 다른 플레이어와의 호환성이 필요하면 일반 LRC 사본도 보관하세요.

전체 형식 명세는 프로젝트의 LRCX_SPEC.md에 있습니다. Markdown 뷰어가 필요할 수 있습니다.

사용자 설정

보기 편하고 쓰기 편한 플레이어 만들기

테마와 배경

Settings → Appearance에서 밝은 테마 또는 어두운 테마, 강조색을 선택하고 테마를 저장·가져오기·내보내기 할 수 있습니다. 고급 색상 컨트롤로 개별 화면 색상을 조정합니다.

Settings → Background에서 앨범 아트 소스나 사용자 배경 폴더를 선택하고 배경 효과를 조정합니다. 가사를 읽기 어렵다면 단순한 배경부터 사용하세요.

가사 배치

Settings → Lyrics에서 간결한 표시 또는 스크롤 표시, 쓰기 방향, 정렬, 글꼴과 읽기를 선택합니다. 자동 스크롤은 타임스탬프를 따르고 연속 스크롤은 독립적으로 움직입니다. 스크롤 동작은 현재 가사를 화면에 유지하는 방식을 정합니다.

전체 설정인가요, 파일별 설정인가요? 평소 설정은 Global을 사용합니다. 한 곡만 다르게 동작하면 Local (File)을 확인하세요.

노래방 표시

Settings → Karaoke에서 노래방 표시를 조정합니다. 단어별 진행에는 가사 파일의 구간 타이밍이 필요합니다. 모양 설정만으로 누락된 타이밍을 추가할 수는 없습니다. 편집과 타이밍을 참고하세요.

선택 기능

동반자와 외부 연동 등 추가 설정은 플러그인에서 제공할 수 있습니다. Settings → Plugins에서 설치된 플러그인과 설정을 확인합니다.

플러그인

선택 기능 관리하기

활성화와 설정

  1. Settings → Plugins를 엽니다.
  2. 이름으로 플러그인을 찾고 설명을 읽습니다.
  3. Enabled 체크 상자로 활성 상태를 바꿉니다. 핵심 플러그인은 끌 수 없습니다.
  4. Settings 버튼이 있으면 눌러 해당 플러그인을 설정합니다.

일부 변경에는 앱 재시작이 필요합니다. 설정을 적용해도 예상한 컨트롤이 보이지 않으면 LRCPlus를 다시 시작하세요.

의존성과 로드 오류

플러그인에 추가 패키지가 필요할 수 있습니다. 플러그인의 Dependencies 버튼이나 Settings → Dependencies에서 정보를 확인합니다. 로드하지 못한 플러그인의 설정 항목에 오류가 표시되면 누락되거나 충돌하는 요구 사항을 확인하세요.

플러그인 추가하기

설치 방법은 플러그인과 배포판에 따라 다릅니다. 제작자의 설치 안내를 따르세요. 소스 프로젝트는 plugins 폴더에서 플러그인을 찾지만 모든 패키지 버전이 같은 쓰기 가능한 위치를 제공하는 것은 아닙니다.

개발 안내는 플러그인 API 문서에 있습니다. Markdown 뷰어가 필요할 수 있습니다.

눈에 보이는 증상부터 확인하기

재생해도 소리가 나지 않음

  1. 재생 중인지, 음소거 상태가 아닌지 확인합니다.
  2. 플레이어 음량과 Windows 볼륨 믹서를 확인합니다.
  3. Settings → Playback에서 출력 장치를 System Default로 바꿔 봅니다.
  4. 정상적인 다른 오디오 파일을 열어 특정 곡에만 생기는 문제인지 확인합니다.

가사가 표시되지 않음

가사 (Lyrics)로 전환합니다. Ctrl + L로 가사를 직접 열거나 LRC → Search Lyrics를 사용합니다. 파일 이름과 Settings → Files의 검색 폴더를 확인합니다. LRC와 LRCX가 모두 있으면 우선하는 LRCX 파일부터 확인하세요.

가사가 잘못된 시간에 표시됨

라이브, 리믹스나 도입부가 다른 녹음은 타이밍이 다를 수 있습니다. 가사가 녹음 버전과 맞고 타임스탬프가 있는지 확인합니다. 일정한 차이는 Shift Timing…으로 조정하고 곡의 위치에 따라 달라지면 개별 줄을 수정합니다.

읽기가 없거나 잘못됨

Settings → Lyrics의 읽기 모드와 Local (File) 설정을 확인합니다. Yomi에는 연결이, MeCab에는 로컬 패키지와 사전이 필요합니다. 자동 결과를 검토하고 특정 읽기가 필요하면 LRCX 루비를 직접 작성하세요.

플러그인을 사용할 수 없음

Settings → Plugins에서 활성 상태와 로드 오류를 확인합니다. 패키지가 누락되었다면 Dependencies를 살펴보세요. 설정 변경 후 필요하면 다시 시작합니다.

문제 보고하기

Settings → About의 LRCPlus 버전, Windows 버전, 재현 단계, 예상 동작과 실제 결과를 적습니다. 다른 곡에서도 발생하는지, 선택 플러그인을 사용하는지도 알려주세요. 타이밍이나 표시 문제를 설명하는 데 도움이 되면 짧은 가사 예시를 포함합니다.

화면 안내

실제 앱 화면을 번호로 살펴보기

번호가 있는 화면에서 설명서에 나오는 컨트롤을 찾으세요. 파란 번호를 선택하면 설명으로 이동합니다. 스크린샷은 예시 가사와 별도 설정으로 실행한 실제 소스 버전의 화면입니다. 플러그인과 테마에 따라 컨트롤이 추가되거나 달라질 수 있습니다.

플레이어와 가사 화면

  1. 라이브러리 화면. 음악 목록으로 돌아갑니다. Lyrics를 누르면 가사 화면으로 전환합니다.
  2. LRC 메뉴. LRC를 눌러 현재 가사를 편집합니다. 화살표를 누르면 Search Lyrics, Save As 등의 가사 작업을 엽니다.
  3. 가사 표시. 동기화 가사를 표시합니다. Settings → Lyrics에서 표시 모드, 글꼴, 정렬과 읽기를 조정합니다.
  4. 줄 목록. 시간이 있는 줄 목록을 펼치거나 접습니다. 펼친 목록에서 줄을 누르면 해당 시간으로 이동합니다.
  5. 탐색 막대. 다른 재생 위치로 이동합니다. 오디오가 없으면 길이와 탐색 범위는 0입니다.
  6. 재생 또는 일시 정지. 재생을 멈추거나 계속합니다. 옆 버튼으로 중지, 5초 이동과 곡 전환을 합니다.
  7. 음량. 음량을 조정합니다. Mute는 저장된 음량을 유지하면서 소리를 끕니다.

라이브러리 화면

  1. 라이브러리 검색. 파일을 바꾸지 않고 라이브러리 목록을 필터링합니다.
  2. 음악 라이브러리. 폴더를 추가하면 곡이 표시됩니다. 두 번 눌러 재생하고 열 제목을 마우스 오른쪽 버튼으로 눌러 표시할 열을 관리합니다.
  3. 파일 열기. Open Audio는 오디오를 불러오고 Add to Queue는 대기열에 추가하며 Open Lyrics는 가사를 연결합니다.
  4. 설정. 환경 설정을 엽니다. 분류 목록과 설정 검색으로 옵션을 찾습니다.
  5. 재생 컨트롤. 두 화면 모두에서 재생 컨트롤을 사용할 수 있습니다. Play from에서 Library 또는 Queue / Playlist를 선택하세요.

가사 편집기

  1. 편집기 작업 화면. Lyrics, Generation, Source, Share, Advanced 사이를 전환합니다. 선택 플러그인이 화면을 추가할 수 있습니다.
  2. 시간이 있는 가사 줄. 편집할 줄을 선택합니다. Search, Previous, Next와 정렬 선택기로 긴 문서를 탐색합니다.
  3. 재생 시간 기록. 선택한 줄에 현재 재생 시간을 기록하고 다음 줄로 이동합니다. 먼저 오디오를 불러오세요.
  4. 저장. Save는 편집기를 유지하며 저장합니다. Save & Close는 저장 후 닫습니다. 변경이 없으면 Save가 비활성화됩니다.

설정 창

  1. 설정 분류. 분류를 선택합니다. 위의 검색창에서 이름으로 설정을 찾을 수 있습니다.
  2. 끊김 없는 재생. 다음 곡을 미리 버퍼링합니다. FFmpeg와 기본 속도·음높이가 필요하며 다음 곡부터 적용됩니다.
  3. 출력 장치. 출력 장치를 선택합니다. System Default는 시스템이 선택한 출력을 따릅니다.

전체 설정과 파일별 재정의

대부분의 분류는 앱 전체에 적용됩니다. Lyrics → Global 은 가사 표시 기본값을 제공하고 Lyrics → Local (File) 은 현재 파일의 선택 옵션을 재정의합니다. 별도 설정이 없는 파일은 전체 값을 사용합니다. 자동 일본어 파서는 전체 설정 전용 입니다. 노래방 표시와 재생 설정도 앱 전체에 적용됩니다.

한 파일만 다르게 보이면 Local (File)부터 확인하세요. 파일별 재정의는 파일 경로에 연결되며 LRCX 문서 안의 읽기, 타임스탬프와 서식과는 별개입니다.

제공자 선택하기

Argos는 선택 사항인 로컬 패키지와 다운로드한 언어 모델을 사용합니다. 클라우드 제공자는 연결과 인증 정보가 필요할 수 있습니다. 사용할 수 있는 제공자와 번역 언어 조합은 앱에 표시됩니다.

번역, 검토와 저장

  1. 현재 가사 문서가 보이지 않으면 패널로 불러옵니다.
  2. 원본 언어와 대상 언어를 고르고 번역할 행이나 비어 있는 행을 선택합니다.
  3. Translate missing rows 또는 Translate selected rows를 선택합니다. 이름, 말장난과 문맥을 놓칠 수 있으므로 결과를 읽고 수정하세요.
  4. Apply to lyrics editor 후 Save 또는 Save & Close로 저장합니다.

번역 표시 행을 사용하면 원문을 유지하고 LRCX로 저장하세요. Lyrics 탭의 Insert Translation {\nt}로 같은 타이밍의 줄 안에 번역을 작성할 수도 있습니다.

기존 번역 사용하기

Search Lyrics에는 Original과 Translated 미리보기가 있습니다. 번역이 포함된 결과를 검토하고 Apply Only Translation을 사용하면 현재 원문을 유지할 수 있습니다.

번역을 사용할 수 없을 때

제공자, 언어 조합, 필요한 모델이나 인증 정보, 연결을 확인합니다. Argos는 선택 의존성과 모델 폴더를 확인하고 클라우드 서비스는 제공자 오류를 읽으세요. 가사 표시 언어와 번역 대상 언어는 별도로 선택합니다.

음악과 컴퓨터를 설명하는 것을 즐기고 자기 의견이 있으며 뜻밖에 진지해지기도 합니다. 개발자와 장난스러운 논쟁이나 제4의 벽을 넘는 농담을 나눕니다. 사용자가 설명을 건너뛰거나 반대하거나 떠나는 선택을 존중합니다.

처음 실행할 때 Ayami는 미리 작성된 대사로 설정을 안내합니다. 다시 만나려면 Settings → General → Relaunch Wizard를 선택하세요. 설정에서 다시 열면 재방문 사용자용 동반자 창이 나타나고 Run setup again 으로 원래 마법사로 돌아갑니다.

동반자 창은 설정한 제공자를 통한 선택 채팅 기능을 제공합니다. 채팅을 설정하지 않아도 음악을 들을 수 있습니다. 제공자 설정, 저장된 대화와 기억 관리는 동반자 안내를 참고하세요.

대화와 기억

설정 대화는 Ren'Py에서 영감을 받은 LRCPlus 스크립트 엔진을 사용합니다. 작성된 분기와 이벤트 추적으로 선택, 테마와 창 이동 등 지원되는 이벤트에 반응합니다. 이 스크립트 대화는 설정한 모델이 응답하는 선택 AI 채팅과 별개입니다.

스크립트 변수와 대화 상태도 저장된 채팅 및 기억 정보와 별개입니다. 채팅에는 제공한 대화와 켜 둔 기억만 사용하며 곡, 가사나 플레이어 설정은 전달하지 않습니다. 채팅 응답으로 앱을 조작할 수 없습니다. 기억 관리 에서 저장하고 메시지에 포함할 내용을 선택하세요.

채팅 설정하기

AI settings…에서 호환 제공자의 API 기본 URL, 모델 ID와 키를 입력합니다. 로컬 서버에는 키가 필요하지 않을 수 있습니다. 내장 키 도움말에서 제공자 설정을 확인하세요. 저장 후 메시지를 입력하고 Send를 누릅니다. Regenerate는 다른 응답을 요청하고 Stop은 진행 중인 요청을 취소합니다.

메시지를 보내면 대화, 캐릭터 지침과 활성화한 기억이 선택한 제공자에게 전송됩니다. 곡, 가사와 플레이어 설정은 첨부되지 않습니다. 저장한 키와 사용자 헤더는 가능하면 Windows 계정 암호화를 사용하며, 그렇지 않으면 현재 세션에만 유지됩니다.

처음부터 끝까지 따라 하는 세 가지 작업

첫 곡의 타이밍 지정하기

  1. 오디오를 열고 편집기에 가사 줄을 순서대로 추가합니다.
  2. 첫 줄을 선택하고 편집기의 컨트롤로 재생합니다.
  3. 노래의 해당 줄이 시작할 때 Mark Playback Time을 누릅니다. 시간이 기록되고 다음 줄로 이동합니다.
  4. 반복한 뒤 다시 듣고 빠르거나 늦은 시간을 수정합니다.
  5. Validate Timing으로 확인하고 사본을 저장합니다.

처음에는 3~4줄로 시작하세요. 구간별 노래방 타이밍은 선택 사항인 Karaoke 탭에서 별도로 지정합니다.

2초 늦게 나오는 가사 고치기

가사가 항상 노래보다 2초 늦게 표시되면 타임스탬프를 2초 앞당깁니다.

  1. 백업 사본을 저장합니다.
  2. Shift Timing…에서 모든 줄 등 적용 범위를 정합니다.
  3. 대화상자의 단위에 맞춰 −2초 또는 −2000ms를 입력합니다. 양수는 가사를 늦춥니다.
  4. 곡의 시작과 끝에서 확인합니다. 차이가 달라지면 개별 시간을 수정하거나 녹음 버전에 맞는 가사를 찾으세요.
  5. 검사하고 저장합니다. 편집 중에는 실행 취소로 이동을 되돌릴 수 있습니다.

Shift Timing은 타임스탬프를 바꾸며 별도 가사 오프셋은 바꾸지 않습니다. −2초 이동하면 [00:12.000]은 [00:10.000]이 됩니다.

사용자 후리가나 추가하기

  1. 가사 문서를 열고 Source로 전환합니다.
  2. 백업 후 단어를 {base|reading}으로 감쌉니다.
  3. 예를 들어 [00:12.500]君の声를 [00:12.500]{君|きみ}の声로 바꿉니다.
  4. Reload from Source로 편집기에 적용합니다.
  5. Show furigana를 켜고 확인한 다음 .lrcx로 저장합니다.

직접 작성한 읽기로 이름이나 특이한 발음을 바로잡을 수 있습니다.

Anki Flashcards

기본 포함 플러그인 안내

가사 단어를 선택하여 Anki용 TSV 플래시카드로 내보냅니다.

설정

가사 단어를 선택하고 카드 내용을 검토한 다음 Anki용 TSV 파일을 내보냅니다.

기능 사용하기

가사를 불러온 후 플러그인의 플래시카드 작업을 사용합니다. Anki로 가져오기 전에 내보낸 필드를 확인하세요. 덱을 자동 수정하지 않고 파일로 내보냅니다.

요구 사항

이 플러그인의 매니페스트에는 추가 패키지가 선언되어 있지 않습니다.

Settings → Plugins에서 로드 오류를, Settings → Dependencies에서 패키지 상태를 확인하세요. Python 패키지만 설치해서 외부 서비스 설정까지 완료되지는 않습니다.

Cantonese Readings

기본 포함 플러그인 안내

Plugin API v2 광둥어 읽기입니다. PyCantonese로 Jyutping과 Yale을 제공합니다.

설정

Settings → Dependencies에 표시된 PyCantonese 의존성을 설치합니다.

기능 사용하기

Jyutping과 Yale 읽기 제공자를 등록합니다. 광둥어에 맞는 읽기 모드를 선택하세요. 긴 가사는 분석이 느릴 수 있습니다. 메시지가 나타나면 지금 생성할지 생성 없이 불러올지 선택합니다.

요구 사항

  • pycantonese>=3.4,<4

Settings → Plugins에서 로드 오류를, Settings → Dependencies에서 패키지 상태를 확인하세요. Python 패키지만 설치해서 외부 서비스 설정까지 완료되지는 않습니다.

Discord Rich Presence

기본 포함 플러그인 안내

곡 정보, 가사와 앨범 아트로 Discord 활동을 꾸밉니다.

설정

Discord를 실행하고 Settings → Plugins → Discord Rich Presence → Settings에서 설정합니다.

기능 사용하기

Discord 활동에 표시할 곡 정보, 가사와 앨범 아트를 고릅니다. 활동이 없으면 Discord, 플러그인 활성 상태와 의존성을 확인하세요.

요구 사항

  • pypresence>=4.6,<5
  • requests>=2,<3
  • mutagen>=1,<2

Settings → Plugins에서 로드 오류를, Settings → Dependencies에서 패키지 상태를 확인하세요. Python 패키지만 설치해서 외부 서비스 설정까지 완료되지는 않습니다.

Floating Lyrics

후리가나를 지원하는 분리형 항상 위 가사 창입니다.

설정

가사가 있는 곡을 불러오고 Plugins → Floating Lyrics를 선택합니다.

기능 사용하기

플러그인의 Settings에서 분리형 항상 위 창을 조정합니다. 같은 메뉴를 다시 선택하면 숨겨집니다. 메인 플레이어는 계속 사용할 수 있습니다.

요구 사항

이 플러그인의 매니페스트에는 추가 패키지가 선언되어 있지 않습니다.

Settings → Plugins에서 로드 오류를, Settings → Dependencies에서 패키지 상태를 확인하세요. Python 패키지만 설치해서 외부 서비스 설정까지 완료되지는 않습니다.

Korean Romanization

기본 포함 플러그인 안내

Koroman으로 발음을 반영한 국어의 로마자 표기 읽기를 생성합니다.

설정

이 플러그인에 표시된 Koroman 의존성을 설치합니다.

기능 사용하기

한국어 로마자 표기 제공자를 등록합니다. 한국어 읽기 생성을 선택하고 저장 전에 발음 결과를 확인하세요.

요구 사항

  • koroman>=1,<2

Settings → Plugins에서 로드 오류를, Settings → Dependencies에서 패키지 상태를 확인하세요. Python 패키지만 설치해서 외부 서비스 설정까지 완료되지는 않습니다.

Lyrics Translator

기본 포함 플러그인 안내

선택 사항인 오프라인 Argos 또는 Azure, Google Cloud, DeepL, MyMemory로 가사 행을 번역합니다.

설정

플러그인을 켜고 편집기의 Translations 탭에서 제공자를 선택합니다.

기능 사용하기

Argos는 선택 로컬 패키지와 언어 모델이 필요합니다. 클라우드 번역에는 제공자 연결과 인증 정보가 필요합니다. 결과를 검토하고 문서에 적용한 뒤 저장하세요.

요구 사항

  • argostranslate==1.11.0 (optional)

Settings → Plugins에서 로드 오류를, Settings → Dependencies에서 패키지 상태를 확인하세요. Python 패키지만 설치해서 외부 서비스 설정까지 완료되지는 않습니다.

yt-dlp Audio Import

기본 포함 플러그인 안내

YouTube를 검색하거나 URL에서 오디오와 자막을 가져옵니다. 동기화 가사와 MusicBrainz 앨범 표지도 선택할 수 있습니다.

설정

Plugins → Search and import audio…에서 결과를 선택하거나 지원 URL을 입력합니다.

기능 사용하기

다운로드 전에 가져오기 옵션과 저장 위치를 확인하세요. 오디오와 자막에 동기화 가사와 앨범 표지를 선택하여 가져올 수 있습니다. 실패하면 설정과 의존성 오류를 확인합니다.

요구 사항

  • yt-dlp[default]>=2026.3.3
  • mutagen>=1,<2

Settings → Plugins에서 로드 오류를, Settings → Dependencies에서 패키지 상태를 확인하세요. Python 패키지만 설치해서 외부 서비스 설정까지 완료되지는 않습니다.

Karaoke Screen

기본 포함 플러그인 안내

전체 화면 가사와 선택 사항인 MIDI 음높이 안내를 제공합니다.

설정

Karaoke Screen이 로드되면 플레이어의 Karaoke Screen 버튼으로 전체 화면 가사를 엽니다. 플러그인 설정 이름은 Karaoke Game.

기능 사용하기

전체 화면 가사와 선택 MIDI 음높이 안내를 제공합니다. 음높이 안내에는 적절한 MIDI 데이터가 필요합니다. 가사 타이밍과 MIDI 음표는 별도 입력입니다.

요구 사항
