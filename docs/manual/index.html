About this manual

This manual describes the controls in the current source version of LRCPlus. Available features can vary with your build and enabled plugins. Menu paths such as Settings → Lyrics describe what to click in the app.

This manual is available online and bundled with the app. The bundled copy supports offline reading and search. Features that retrieve lyrics or use an online reading provider still need an internet connection.

Getting started

Your first song in LRCPlus

LRCPlus plays music alongside synchronized lyrics, with optional reading aids and karaoke timing. You can start with a single audio file.

Play your first song

  1. Launch LRCPlus. If the setup wizard appears, follow its prompts.
  2. Choose Open → Open Audio…, or press Ctrl + O, and select an audio file.
  3. Use Play to start or pause playback.
  4. Choose Lyrics to switch to the lyric display, or Library to return to your music.

Add lyrics

If you have a matching lyrics file, choose Open → Open Lyrics… (Ctrl + L). Otherwise choose LRC → Search Lyrics to look online. See Finding lyrics for the full workflow.

Try a matching filename. Keep Song.mp3 and Song.lrc (or Song.lrcx) together. When both lyric formats exist, LRCPlus prefers LRCX.

What next?

  • Add music folders to the library.
  • Turn on furigana or romaji.
  • Correct a lyric line.

You can reopen the setup wizard from Settings → General → Relaunch Wizard.

Music and playback

Your library, queue, and playback controls

Build a music library

  1. Switch to Library.
  2. Click Add Music Folder and choose a folder containing your music.
  3. Use Rescan after changing the files in your music folders.

Use Remove Folder to manage which folders belong to the library.

Use the queue

Choose Open → Add to Queue… (Ctrl + Shift + O) to add files. The playback source selector offers Library and Queue / Playlist; check this selector if the player advances through a different set of tracks than you expect.

Playback preferences

In Settings → Playback, choose an output device, track or album shuffle, and what happens after playback: next track, stop, repeat all, or repeat track. Start with System Default for output if you are unsure which device to use.

Finding lyrics

Load a file or search for the right version

Open local lyrics

Load your song, then choose Open → Open Lyrics… and select an .lrc or .lrcx file. Matching filenames alongside your audio help automatic discovery. You can manage additional lyric search folders in Settings → Files.

Search online

  1. Load the song you want lyrics for.
  2. Choose LRC → Search Lyrics.
  3. Check the search details and click Search.
  4. Select a result and read its preview. Check the artist and song version, especially for live recordings and remixes.
  5. Click Use Selected Lyrics to apply that result.

Some providers require credentials. LRCLIB integration supports synchronized and plain-text lyrics. Online search requires a connection.

Synchronized versus plain text

Synchronized lyrics contain timestamps that tell the player when each line begins. Plain lyrics provide the words without those timings. If text appears but does not follow the song, check whether the result contains timestamps. You can add them in the lyrics editor.

Keep a local copy

Use LRC → Save As… to save lyrics to a file you choose. Prefer .lrcx when you need readings, karaoke timing, or formatting. Check your save location so you can find the file again.

Furigana and readings

Reading aids for your lyrics

Furigana are small readings displayed alongside Japanese lyric text. Romaji displays readings using Latin letters. Saved LRCX ruby can also provide explicitly authored readings.

Choose a reading display

  1. Open Settings → Lyrics.
  2. Choose Global for general defaults or Local (File) for the current file.
  3. Enable Show furigana, Show romaji, or All romaji. These modes are mutually exclusive.
  4. Use Ruby position to place furigana above or below the lyrics.

Choose an automatic parser

ParserRequirements
YomiAn online Japanese reading provider; needs an internet connection.
MeCabA local, optional parser; requires fugashi and a dictionary installed separately.

The parser selector is in the lyric settings. See Settings → Dependencies for dependency information.

Generate and correct readings

Open LRC → Edit Lyrics, then use the Generation tab. Choose Generate readings for all lyrics or Generate For This Timestamp. Automatic readings can be wrong for names, unusual spellings, and lyrics with wordplay; review them before saving.

To preserve an authored reading in LRCX, use {base|reading}, for example {君|きみ}. See the LRCX reference.

Editing and timing

Correct the words and make them follow the music

Load a song and choose LRC → Edit Lyrics. Save a separate copy before making substantial timing changes.

Edit lyric lines

In the Lyrics tab, select a line and edit its text. Use + Add Line, Delete Line, Move Up, and Move Down to manage the document. Formatting controls include bold, italic, strikethrough, underline, and Quote.

Set line timing

  1. Select the line you want to time.
  2. Use the editor playback controls to find where the line starts. The Waveform control helps you inspect the audio.
  3. Use Mark Playback Time at the line start. This updates the selected line and advances to the next one. When adjusting provisional waveform markers instead, use Commit to apply their timing.
  4. Play the passage again and check that the lyric follows the music.

Use Shift Timing… for a consistent timing adjustment, and Validate Timing to check timing issues. Test a short section before applying a broad shift.

Time karaoke segments

In the Karaoke tab, use Automatic Separation to prepare segment boundaries, review them, and choose Apply Separation. Use Mark Playback Time [F] while working through the segments. Listen back to verify the result; automatic separation does not guarantee accurate timing.

Source and saving

The Source tab exposes the timed lyric text. Refresh Source and Reload from Source move between the structured editor and source text. Save a copy before reloading source that may replace edits.

Save as .lrcx to retain LRCX features. See LRCX reference for syntax and examples.

LRCX reference

A practical guide to enhanced lyric files

LRCX extends LRC with karaoke segment timing, ruby readings, and text formatting. Ordinary LRC files still work.

Timestamps

[00:12.500]The line begins here
[00:16.000]<00:16.000>One <00:16.500>word <00:17.000>at a time

A square-bracket timestamp marks a line start. An angle-bracket timestamp marks a karaoke segment start. Times use minutes, seconds, and milliseconds.

Ruby readings

[00:12.500]{君|きみ}の声

The text before | is the base lyric; the text after it is the reading.

Formatting and display rows

SyntaxEffect
**bold**Bold
*italic*Italic
~~text~~Strikethrough
<u>text</u>Underline
{\n}A new visual row in the same timed line
> textA blockquote when placed immediately after the line timestamp
[00:12.500]**First row**{\n}Second row
[00:16.000]> A quoted lyric

The visual newline marker is the literal text {\n}, not a new timestamp. In the editor, use Insert Newline {\n}.

Metadata and compatibility

[ar:Artist]
[ti:Song title]
[al:Album]

Use the .lrcx extension to preserve these enhanced features. Other lyric players may not understand the extensions. Keep an ordinary LRC copy when you need compatibility with another player.

For the complete format specification, see LRCX_SPEC.md in the project source (a Markdown reader may be needed).

Customization

Make the player comfortable to read and use

Appearance and backgrounds

Open Settings → Appearance to choose a light or dark theme, change accent colors, and save, import, or export themes. Advanced color controls let you adjust individual interface colors.

In Settings → Background, choose an artwork source or custom background folders and adjust the background treatment. Start with a simple background if the lyric text is difficult to read.

Lyric layout

In Settings → Lyrics, choose compact or scrolling display, writing direction, alignment, font, and reading options. Automatic scrolling follows timestamps; continuous scrolling moves independently of them. Scroll behavior controls how the current lyric stays in view.

Global or local? Use Global for your normal preferences. Check Local (File) when one song behaves differently from the others.

Karaoke appearance

Use Settings → Karaoke to customize karaoke display. Word-by-word progress needs segment timing in the lyric file; appearance settings cannot add missing timing. See Editing and timing.

Optional features

Additional settings and controls may come from plugins, including optional companion features and integrations. Open Settings → Plugins to see the plugins available in your installation and their settings.

Plugins

Manage optional features

Enable and configure

  1. Open Settings → Plugins.
  2. Find the plugin by name and read its description.
  3. Use its Enabled checkbox to change whether it is enabled. Core plugins cannot be disabled.
  4. If a Settings button appears, use it to configure that plugin.

Some changes may need an app restart. If the expected controls do not appear after applying settings, restart LRCPlus.

Dependencies and load errors

A plugin may require additional packages. Use its Dependencies button, or open Settings → Dependencies, to inspect dependency information. A plugin that fails to load can show an error in its settings entry; use that message to identify the missing or conflicting requirement.

Adding plugins

Plugin installation is specific to the plugin and distribution. Follow the plugin author's installation instructions. The source project discovers plugins from its plugins directory; do not assume that every packaged version exposes the same writable location.

For plugin authors, the separate Plugin API documentation covers development (a Markdown reader may be needed).

Troubleshooting

Start with the symptom you can see

Playback is silent

  1. Check that playback is running and the player is not muted.
  2. Check the player volume and Windows volume mixer.
  3. In Settings → Playback, try System Default as the output device.
  4. Try another known-working audio file to see whether the issue is specific to one song.

Lyrics do not appear

Switch to Lyrics. Open the lyric file explicitly with Ctrl + L, or use LRC → Search Lyrics. Check filenames and the search folders under Settings → Files. If both LRC and LRCX files exist, check the LRCX file first because it takes priority.

Lyrics appear at the wrong time

Confirm that the lyrics match the recording: live versions, remixes, and different intros often have different timings. Check whether the file has timestamps. Use Shift Timing… in the editor for a consistent offset, or correct individual lines when the mismatch changes throughout the song.

Readings are missing or incorrect

Check the reading mode in Settings → Lyrics, including any Local (File) settings. Yomi requires a connection; MeCab requires its local packages and dictionary. Review automatic output and use authored LRCX ruby when a word needs a specific reading.

A plugin is unavailable

Look in Settings → Plugins for its enabled state and load error. Inspect Dependencies if required packages are missing. Restart after configuration changes if needed.

Report a problem

Include your LRCPlus version from Settings → About, Windows version, steps to reproduce, expected behavior, and what happened instead. Note whether the issue happens with other tracks and whether optional plugins are involved. Include a small lyric example when it helps explain a timing or rendering issue.

Interface guide

A numbered tour of the actual application

Use these numbered views to find the controls described throughout the manual. Select a blue number to jump to its explanation. Screenshots show the actual source interface with sample lyrics and isolated preferences; plugins and your theme may add or change controls.

Player and lyrics workspace

  1. Library workspace. Switch back to your music collection; Lyrics returns to this view.
  2. LRC menu. Click LRC to edit the current lyrics. Its arrow opens Search Lyrics, Save As, and other lyric actions.
  3. Lyric display. The synchronized lyric appears here. Settings → Lyrics controls display mode, font, alignment, and readings.
  4. Line list. Expand or collapse the timed-line list. Click a line in the expanded list to jump to its time.
  5. Seek bar. Move to another playback position. With no audio loaded, duration and seek range remain zero.
  6. Play or pause. Pause or resume playback. Adjacent buttons stop, skip five seconds, or change tracks.
  7. Volume. Adjust volume; Mute silences output without discarding the saved volume level.

Library workspace

  1. Search the library. Filter your library without changing its files.
  2. Music library. Tracks appear here after you add a folder. Double-click a track to play it; right-click column headings to manage visible columns.
  3. Open files. Open Audio loads a file; Add to Queue appends files; Open Lyrics attaches a lyric file.
  4. Settings. Open preferences. Use the category list and settings search to find an option.
  5. Playback controls. Transport controls stay available in both workspaces. Check Play from to select Library or Queue / Playlist.

Lyrics editor

  1. Editor workspaces. Switch between Lyrics, Generation, Source, Share, and Advanced. Optional plugins can add workspaces.
  2. Timed lyric lines. Select the line to edit. Search, Previous, Next, and the order selector help navigate long documents.
  3. Mark Playback Time. Stamp the selected line with current playback time and advance to the next line. Load audio before timing.
  4. Save. Save writes changes and keeps the editor open. Save & Close writes and exits; Save is disabled when there are no changes.

Settings window

  1. Settings categories. Select a category. The search field above the categories helps locate a setting by name.
  2. Gapless playback. Enable next-track prebuffering. This needs FFmpeg and normal speed and pitch; it takes effect on the next track.
  3. Output device. Choose the output device. System Default follows the system-selected output.

Settings reference

Options, factory defaults, and where they apply

This reference lists player and lyric controls with their factory defaults. Saved preferences, a setup preset, or per-file overrides may produce different values. Open Settings and select the named category; use settings search when you know an option name.

Global settings and file overrides

Most categories apply to the application. Lyrics → Global supplies lyric display defaults, while Lyrics → Local (File) overrides selected options for the current file. A file without an override inherits the global value. The automatic Japanese parser is a global-only choice. Karaoke appearance and playback preferences are also application-wide.

If one file looks different, check Local (File) first. A file override is associated with its file path; it is distinct from readings, timestamps, and formatting stored inside an LRCX document.

Translations

Keep original lyrics and translated rows together

Choose a provider

Enable Lyrics Translator in Settings → Plugins. Load a song with timed lyrics and open LRC → Edit Lyrics → Translations. Choose a provider from the Provider selector. If the tab is absent, check that a translation provider is enabled and loaded.

Argos uses optional local packages and downloaded language models. Cloud providers need a connection and may require credentials. The available providers and language routes are shown in the app.

Translate, review, and save

  1. Load the current lyric document into the panel if it is not already shown.
  2. Choose source and target languages, then select the rows or missing rows to translate.
  3. Choose Translate missing rows or Translate selected rows. Read and edit the output; automatic translation may miss names, wordplay, or context.
  4. Choose Apply to lyrics editor, then use Save or Save & Close.

Keep the original rows and save as LRCX when using translation display rows. The Lyrics tab also has Insert Translation {\nt} for authoring a translation within a timed line.

Use an existing translation

Search Lyrics includes Original and Translated previews. When a result provides translated lyrics, review it and use Apply Only Translation to preserve the current original text.

If translation is unavailable

Check the provider, language route, required models or credentials, and connection. For Argos, inspect the optional dependency and models folder. For cloud services, read the provider error. The lyric display language and translation target are separate choices.

Sharing and image cards

Export text or make a lyric image

Copy or export text

  1. Open LRC → Edit Lyrics → Share → Text.
  2. Choose Plain text for words alone or With line timestamps for timed lines.
  3. Use Copy for the clipboard or Export… for a file.

This shares lyric text, not audio. Use the editor Save actions to preserve the full editable LRCX document.

Create an image card

  1. Open Share → Image card in the editor.
  2. Choose the excerpt using the checked-line selection and review the preview.
  3. Choose a layout template, then adjust text, artwork, and background settings.
  4. Export the image using the card controls.

Templates include Classic, Spotlight, Record sleeve, Polaroid, Editorial, and Cinema. Artwork is optional; Cinema can use album artwork as a blurred backdrop.

Readings and formatting

Preserve LRCX formatting keeps inline emphasis, quote styling, visual breaks, and smaller translation rows. Furigana is controlled separately and uses authored or already-generated readings; image cards do not start reading providers. Generate missing readings in the editor first.

Typography supports horizontal and vertical writing. Song details include title, artist or credit, and album. Check the preview for clipped text or missing font characters before export. Timestamps and playback karaoke highlighting are not printed on the card.

Sakurabayashi Ayami (櫻林 純美), usually called Ayami, is the fictional character who personifies the LRCPlus setup wizard. She introduces the player, helps with initial configuration, and returns as an optional music companion.

Her character profile describes her as a Computer Science high-school student. Her exact age is undisclosed. Her surname combines 櫻 (cherry blossom) and 林 (grove), reflecting her fondness for sakura.

Personality

Ayami is outgoing, imaginative, theatrical, and easily flustered. She takes helping seriously, even when a straightforward explanation turns into a performance with imaginary clipboards or cue cards. Her voice mixes technical explanations, casual internet slang, dry sarcasm, and occasional profanity.

She enjoys explaining music and computers, has opinions of her own, and can become unexpectedly sincere. Her exchanges with the developer include playful arguments and fourth-wall jokes. She respects a user's choice to skip an explanation, disagree, or leave.

Interests and preferences

Her interests include music, cherry blossoms, typography, poetry, anime, games, drawing, and chocolate. She likes spicy food, snacks, and Japanese cuisine; her stated dislikes include cucumbers, dumplings, and kimchi.

Her hobbies combine creative and technical work: songwriting, video editing, 3D modeling, operating-system tinkering, and programming in Python and C++.

“I prefer Sakura ngl. But this is your player, so my vote is purely decorative.”

Meeting Ayami in LRCPlus

During first-run setup, Ayami guides you through configuration with authored dialogue. To meet her again, choose Settings → General → Relaunch Wizard. Reopening from Settings enters the returning-user companion window; Run setup again returns to the original wizard.

The companion window offers optional chat through a provider you configure. You can use LRCPlus for music without setting up chat. For provider settings, saved conversations, and memory controls, see the Companion guide.

Dialogue and memory

The setup dialogue uses LRCPlus's Ren'Py-inspired script engine. Authored branches and event tracking let Ayami react to choices, themes, window movement, and other supported events. This scripted dialogue is separate from the optional AI chat, whose replies come from the configured model.

Script variables and dialogue state are also separate from saved chat conversations and memory facts. The chat uses the supplied conversation and enabled memories; it does not receive your songs, lyrics, or player settings, and its replies cannot perform app actions. See memory controls to choose what is retained and included in messages.

Character background

Ayami was created to give the onboarding experience a consistent personality. Development began on November 6, 2026; her November 6 birthday commemorates that date. Her humor, branching responses, and expressive reactions are part of that characterization.

The project's character profile records her background and preferences. For the distinction between scripted onboarding and optional chat, see the onboarding documentation (a Markdown reader may be needed).

Companion guide

Ayami chat, conversations, and saved memories

Open the companion

Ayami’s optional chat appears in the companion-enabled setup wizard. Use Settings → General → Relaunch Wizard to revisit setup. Chat is separate from music playback and does not need to be configured to play songs.

Configure chat

Open AI settings… and enter the API base URL, model ID, and key for your compatible provider. A local server may not require a key. The built-in key help explains provider setup. Save, enter a message, and select Send. Regenerate requests another response; Stop cancels a running request.

Sending shares the conversation, character instructions, and enabled memories with the selected provider. Songs, lyrics, and settings are not attached. Remembered keys and custom headers use Windows account encryption when available; otherwise they remain session-only.

Saved conversations

Use the saved-conversation selector to switch chats. New conversation starts another; Rename and Delete manage saved conversations. Previous and Next navigate pages of a longer reply.

Control saved memories

Open Memories… to edit facts, one per line, and choose whether to include them in future messages. Up to 20 facts of 200 characters each are allowed.

Automatic memory mode offers Off, Suggest for approval (the default), and Automatically save ordinary preferences. Extraction can use extra provider requests. Use Review to accept or dismiss suggestions, Sources to inspect their origins, Check now to request a check, or Stop check to cancel it.

Worked tutorials

Three small tasks, from start to finish

Time your first song

  1. Open the audio, then open the editor and add lyric lines in document order.
  2. Select the first line and start playback using the editor controls.
  3. At the beginning of that sung line, choose Mark Playback Time. The editor stamps it and advances to the next line.
  4. Repeat, then listen back and correct late or early marks.
  5. Choose Validate Timing, review the result, and save a copy.

Start with three or four lines. Segment-by-segment karaoke timing is a separate pass in the optional Karaoke tab.

Fix lyrics that are two seconds late

If the lyric consistently appears two seconds after the singer starts, move its timestamps earlier by 2 seconds.

  1. Save a backup copy.
  2. Open Shift Timing… and select the intended scope, such as all lines.
  3. Enter a negative two-second shift using the unit shown by the dialog (−2 seconds or −2000 ms). Positive values move lyrics later.
  4. Listen near the beginning and end. If the mismatch changes, correct individual timings or find lyrics for the correct recording.
  5. Validate and save. Undo reverses a shift while editing.

Shift Timing changes timestamps; the separate lyrics offset remains unchanged. A line at [00:12.000] becomes [00:10.000] after a −2-second shift.

Add custom furigana

  1. Open the lyric document and switch to Source.
  2. Save a backup, then wrap a word using {base|reading}.
  3. For example, change [00:12.500]君の声 to [00:12.500]{君|きみ}の声.
  4. Use Reload from Source to apply the source to the structured editor.
  5. Enable Show furigana, review, and save as .lrcx.

Authored readings let you correct names and unusual pronunciations.

Glossary

Terms used in the player and manual

Terms

Dependency
An additional software package required by a feature or plugin.
FFmpeg
An external audio/video tool used for waveform decoding and gapless playback.
File override
A lyric preference applied to one file instead of its global default.
Furigana
Small Japanese pronunciation readings alongside a base word.
Global setting
A general application or lyric default.
Image card
A lyric excerpt rendered and exported as an image.
Jyutping / Yale
Cantonese romanization systems available through Cantonese Readings.
LRC
A lyric format with line timestamps such as [00:12.500].
LRCX
An extended lyric format supporting segment timing, ruby, formatting, and additional display rows.
Memory
A locally saved companion fact that can be included in messages to your provider.
Offset
An adjustment between the audio timeline and lyric timeline, distinct from editing each timestamp.
Queue
The collection used when Play from is set to Queue / Playlist.
Reading provider
A component that generates pronunciation or romanization readings.
ReplayGain
Loudness and peak metadata used to balance playback levels.
Romaji
A Japanese reading represented using Latin letters.
Ruby
An annotation containing base text and a reading, written in LRCX as {base|reading}.
Segment
A word or smaller chunk of lyric text with its own timing.
Timestamp
A position in a track: a line start or a karaoke segment start.
Translation provider
A component that produces translated text rather than pronunciation readings.
