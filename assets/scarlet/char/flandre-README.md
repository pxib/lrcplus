# Flandre Scarlet boss sprite

`flandre.png` is the user-provided sprite. Scarlet Refrain loads it when
the game window is created, drawing it at its original resolution
without smoothing and preserving its transparency.

Source provided by the user:
https://en.touhouwiki.net/images/6/6d/Th06FlandreSprite.png

The bundled sprite is 49 × 71 pixels. Its body is anchored at (17, 39) so the
magic circle, collision center, and bullet origin remain aligned with Flandre.
If the PNG is missing, the existing vector character remains available.
