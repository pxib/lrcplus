# Reimu Hakurei sprite sheet

`reimu.png` is the unmodified 256 × 256 PNG by **GabrielDrawingsxD**:

https://www.deviantart.com/gabrieldrawingsxd/art/My-new-Reimu-Hakurei-sprite-516844635

Title: My new Reimu Hakurei sprite
Published: February 27, 2015

Character: Reimu Hakurei, from Touhou Project by ZUN / Team Shanghai Alice.

The first three rows contain eight 32 × 48 character frames each. Scarlet
Refrain uses the top row for idle flight and the next two rows for banking.
The effect sprites below those rows are not used. Original transparency is
preserved and the sheet is drawn without smoothing.
